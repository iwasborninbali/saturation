# 3D no-three-in-line: инструменты первого солвера
- `no3_3d.py` — CP‑SAT (точные значения n ≤ 4; при n ≥ 5 не доказывает, замер C2 в SELECTION.md §C).
- `no3_3d.c` — выделенный перебор: DFS по клеткам в лексикографическом порядке, счётчики на прямых (≤ 2),
  отсечение по z‑столбцам; калибровка n = 2,3,4 → 8, 16, 28 ✓; 98 млн узлов/с на ядро; узлы 17 / 3855 / 4.21·10⁷.
  Аргументы: `no3_3d n [start_best] [mask_col0] [mask_col1]` — последние два задают ПРЕФИКС (какие клетки первых двух
  z‑столбцов взяты), что даёт разбиение задачи на независимые куски для распараллеливания.
- `run_prefix.sh` — обёртка для xargs: `cat tasks | xargs -P 11 -I{} ./run_prefix.sh '{}'`, где строки вида `5 40 m0 m1`.
Текущий счёт: n = 5 в решающей форме (стартовый рекорд 40 ⇒ доказываем, что 41 не существует), 256 префиксов, 11 ядер.
Оценка второго солвера (оценщик Кнута, откалиброван против истины с ошибкой 3–4 %): ≈ 2.4·10¹⁴ узлов для этой реализации.
