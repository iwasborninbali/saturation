## Цикл 1. Вопрос 3 плана — «длинные циклы»

**Пример сначала.** При n = 20 среди 117 347 iden-решений один гамильтонов цикл у 30.7 %. Перепись дня (`cycles.py`) сравнила
это с 13.6 % у «случайных» и заключила: решения предпочитают длинные циклы. Но «случайные» там — равномерная **пара**
перестановок (a, b). Одна и та же конфигурация с c циклами получается из 2^c таких пар (в каждом цикле два способа назвать
рёбра строки «a» и «b»), поэтому этот нуль завышает вес конфигураций с многими циклами. Равномерная **конфигурация**
(2 в строке, 2 в столбце — естественный нуль) даёт гамильтоновых 33.3 % при n = 20. Решения — 30.7 %: ниже нуля.

### 1. Правильный нуль (`cycle_null.py nulls`)

P_conf(λ) ∝ 1/(∏ k^{m_k} m_k! · 2^c); нормировка Σ_λ = [tⁿ] (1−t)^{−1/2} e^{−t/2}; (n!)²·Σ = число конфигураций — совпало с
A001499 при n = 8 (187 530 840) и n = 9 (14 398 171 200). Асимптотика: P_conf(гамильтонов) → e^{1/2}√π/(2√n) ≈ 1.46/√n,
P_conf(есть 2-цикл) → 1 − e^{−1/4} = 0.221.

### 2. Лемма о первом моменте (`cycle_null.py moments`, `sample`)

При условии на тип λ распределение конфигурации инвариантно относительно независимых перестановок строк и столбцов, поэтому
для k клеток в попарно разных строках и столбцах P(все заняты | λ) = E[N_k | λ]/(n)_k, где N_k — число систем различных
представителей множеств S_i = {r_i, π⁻¹(r_i)} (π = b⁻¹a — перестановка строк вдоль циклов). Для трёх строк паттерны рёбер π
среди них дают N₃ = 8 (нет рёбер), 6 (одно), 4 (путь из двух), 4 (2-цикл), 2 (3-цикл); их вероятности при типе λ зависят от
m₂, m₃ и L₄ = n − 2m₂ − 3m₃, но сумма схлопывается:
E[N₃ | λ] = 8 − [12·(3m₃(n−3) + L₄(n−4)) + 24L₄ + 24m₂(n−2) + 36m₃]/(n(n−1)(n−2)) = 8 − 12/(n−1) — **без λ**.
Коллинеарные тройки лежат на косых прямых (строки и столбцы несут по 2 точки), значит
**E[#коллинеарных троек | λ] = N₃ᵒᵇˡ(n)·(8 − 12/(n−1))/(n(n−1)(n−2)) для любого типа циклов**: первый момент слеп к длине циклов,
и теоремы вида «короткий цикл порождает много коллинеарных троек в среднем» нет — в среднем ровно столько же.

Проверка: точный E[N₃ | λ] по всем тройкам строк = 7.368421 = 8 − 12/19 для восьми типов при n = 20 (E[N₄], E[N₅] отличаются
между типами лишь в 5-м знаке); N₃ᵒᵇˡ(20) = 59 076, предсказание E[T] = 63.64; выборочные средние по 4000 конфигураций:
(20) 63.83 ± 0.20, (2,18) 63.40 ± 0.19, (3,17) 63.75 ± 0.20, (10,10) 63.51 ± 0.20, (2¹⁰) 63.74 ± 0.20, (4⁵) 63.54 ± 0.20 —
все в пределах 2 SE. **Ставка 1 держится.**

### 4. Что это значит и чего не значит

- Утверждение дня «решения предпочитают гамильтонов цикл (26–31 % против 9–13 %)» — артефакт нуля: сравнивались не те объекты
  (пары перестановок вместо конфигураций). Против правильного нуля знак обратный и слабый.
- Механизм прямоугольника — не в первом моменте (лемма). Он в корреляциях: P(T = 0 | прямоугольник)/P(T = 0) ≈ 1.2 при равном
  E[T]. Кандидат для следующей проверки: 4 точки прямоугольника насыщают только 2 косые прямые (диагонали) вместо 4 у общей
  четвёрки на двух строках — считать распределение T, а не среднее.
- Для симметричных классов (rot2 37 % прямоугольников в переписи дня, rot4/rct4 при n > 20) ни один из двух нулей не годится:
  нужен нуль по инвариантным конфигурациям (симметрия сама навязывает структуру циклов — у rot2 при n = 20 среднее число
  циклов 2.86 против 2.05 у iden). Не измерено; заявлять про n > 20 пока нечего.
