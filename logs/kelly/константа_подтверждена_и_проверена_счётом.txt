Гипотеза Гая–Келли: константа подтверждена независимо, а эвристика впервые сверена
не с максимумами, а с ТОЧНЫМИ КОЛИЧЕСТВАМИ — 2026-08-22, второй решатель
================================================================================

ПОВОД. Гипотеза стоит на эвристике первого момента. Эвристику до сих пор сверяли с
известными максимумами. Но она предсказывает не только порог, а ЧИСЛО расстановок —
а точные числа у нас есть: A000755 на n=2..19 плюс 941580 при n=20 из живой таблицы
Фламменкампа. Сверка предсказанного количества с точным — проверка, которой эвристика
ещё не проходила.

ЧТО ПОСТРОЕНО (с нуля, без чтения чужой реализации)
  T(n) — точное число коллинеарных троек в сетке n x n.
  Порог: ln C(n^2, m) = T(n) * C(m,3) / C(n^2,3).
  Предсказание количества: ln(предсказано) = ln C(n^2,m) - T(n)*C(m,3)/C(n^2,3).

  T(n) посчитано ДВУМЯ независимыми способами: (а) группировкой точек по прямым для
  каждого примитивного направления; (б) через пары концов, gcd(dx,dy)-1 точек между.
  На n=3..12 совпало во всех десяти случаях: 8, 44, 152, 372, 824, 1544, 2712, 4448,
  6992, 10332.

РЕЗУЛЬТАТ 1. КОНСТАНТА — π/√3, ПОДТВЕРЖДЕНО ЧИСЛЕННО И АНАЛИТИЧЕСКИ
  Численно, порог m*(n)/n на растущих n (точный счёт троек, C на lgamma):
        n=  2000  1.9639898        n= 16000  1.9310134
        n=  4000  1.9510508        n= 32000  1.9230747
        n=  8000  1.9402232        n= 64000  1.9161546
  Сходимость логарифмическая. Подгонка m*/n = L + A/ln n по двум последним точкам
  даёт L = 1.81259; с добавленным членом B/(ln n)^2 по трём последним — L = 1.81536.
  Предел лежит между ними:
        L = 1.8138 +- 0.0015
        π/√3                = 1.813799   <- попадание
        (2π^2/3)^(1/3)      = 1.873856   <- в СОРОК раз дальше промаха

  Аналитически. При m = alpha*n и n -> бесконечность:
        ln C(n^2,m) = alpha*n*(ln n + 1 - ln alpha) + O(n)
        T(n)        = (3/pi^2) * n^4 * (ln n - 0.8373) + o(n^4 ln n)
        lambda      = T(n)*(m/n^2)^3 = (3/pi^2)*alpha^3*n*(ln n - 0.8373)
  Приравнивая старшие члены при n*ln n:
        alpha = (3/pi^2) * alpha^3     =>     alpha^2 = pi^2/3     =>  alpha = pi/√3
  Число Гая 1.873856 — это то, что выходит из alpha^3 = 2*pi^2/3. КУБ НА МЕСТЕ КВАДРАТА
  (и двойка). Поправка Эльманна подтверждена нами с нуля, обоими путями.

РЕЗУЛЬТАТ 2. АСИМПТОТИКА ЧИСЛА ТРОЕК — коэффициент пойман до шести знаков
  Измеренный прирост T(n)/n^4 на каждое удвоение n постоянен: 0.210690 (пять удвоений
  подряд, от 2000 до 64000, без дрейфа в шестом знаке).
        (3/pi^2) * ln 2 = 0.210691
  Значит T(n)/n^4 = (3/pi^2)*ln n - 0.2545 + o(1). Проверено обратно: при n=400 формула
  даёт 1.56668, точный счёт 1.566680.

РЕЗУЛЬТАТ 3. СВЕРКА С ТОЧНЫМИ КОЛИЧЕСТВАМИ — ЭВРИСТИКА ЗАВЫШАЕТ
  Семнадцать точек, m = 2n, ln(предсказано) - ln(точно):
     n:    4     5     6     7     8     9    10    11    12
   пром: 2.67  3.60  5.57  6.08  7.13  8.82  9.34 10.59 11.17
     n:   13    14    15    16    17    18    19    20
   пром:12.30 12.90 13.29 13.99 14.66 15.19 15.59 15.88

  Промах положителен всюду и растёт. Проверена также ВТОРАЯ эвристика — независимость
  ПРЯМЫХ вместо троек: она хуже впятеро (промах 61.3 против 15.9 при n=20) и растёт
  линейно без затухания. Тройечный первый момент — лучшая из двух, и это та, что у Гая.

РЕЗУЛЬТАТ 4. ФОРМА ПРОМАХА, И ЧТО ОНА ЗНАЧИТ ДЛЯ КОНСТАНТЫ
  Подгонка по n>=12 (девять точек), среднеквадратичная невязка:
        промах = -11.26 + 9.1130*ln n      невязка 0.133   <- лучшая
        промах =  -4.46 + 4.6006*sqrt n    невязка 0.166
        промах =  +1.62 + 1.5371*n^0.75    невязка 0.186
        промах =  -0.53 + 2.5021*n/ln n    невязка 0.194
        промах =  +4.66 + 0.5768*n         невязка 0.207

  ГЛАВНОЕ. Любая из этих форм есть o(n*ln n), а члены самой эвристики — порядка n*ln n.
  Значит поправка ПОДЧИНЁННАЯ, и константа pi/√3 ею НЕ СДВИГАЕТСЯ. Это утверждение
  об устойчивости: эвристика завышает счёт, но показатель берёт верно.

  Лучшая подгонка — логарифмическая: завышение в ~n^9 раз, то есть ПОЛИНОМИАЛЬНОЕ, а не
  экспоненциальное. Это ровно то, чего ждёшь от первого момента: энтропия верна, неверен
  полиномиальный предмножитель. Данные и теория здесь согласны, что редкость.

ЧТО ЭТИМ НЕ УСТАНОВЛЕНО — и это честная половина
  Конечное n калибровка НЕ фиксирует. Предсказание «последнее n, где расстановка на 2n
  точек ещё существует» по каждой модели:
        ln n     384        n^0.75   197        n        130
        sqrt n   278        n/ln n   172        без калибровки  ~460
  Разброс втрое. Девять точек на n=12..20 не различают эти формы: невязки лежат в
  0.133..0.207, то есть все модели одинаково приемлемы по данным. Ранжирование по
  невязке предпочитает ln n (и теория тоже), но девять точек — это девять точек.

  Для сравнения: решения на 2n точек известны для всех нечётных n<=69 и чётных n<=74,
  наименьший открытый случай n=71, таблица Фламменкампа идёт до n=76. То есть рубеж
  известного (76) лежит НИЖЕ любого из наших предсказаний гибели (130..384).

  Различить формы могло бы одно точное количество при n>=21. Своим инструментом мы его
  не возьмём: до n=20 порядка 500 ядро-лет (запись A000755_calibration.txt).
