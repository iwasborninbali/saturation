Сверка черновика OEIS A399138 — что подтверждено и чем, 2026-08-22
================================================================================

ПОВОД. Хуго Пфёртнер (редактор OEIS) попросил автора подтвердить, что заявка отвечает
требованиям политики «Use of AI for OEIS Submissions». Политика требует от АВТОРА
удостовериться, что члены верны, а формулы доказуемо верны. Ниже — то, что проверено
третьей реализацией проверяльщика, написанной для этой сверки заново.

1. ПОСТРОЕНИЕ a(p) >= p^2 ДЛЯ ПРОСТЫХ — ПОДТВЕРЖДЕНО ПОЛНЫМ ПЕРЕБОРОМ ТРОЕК
   Множество {(x, y, (x^2 - d*y^2) mod p)}, d — квадратичный невычет:
        p= 3:  9 точек,      84 тройки проверены, коллинеарных 0
        p= 5: 25 точек,   2 300 троек,             0
        p= 7: 49 точек,  18 424 тройки,            0
        p=11: 121 точка, 287 980 троек,            0
        p=13: 169 точек, 790 244 тройки,           0
   Перебраны ВСЕ тройки, не выборка. Утверждение черновика воспроизведено.

2. СВИДЕТЕЛИ — ВСЕ ВОСЕМЬ ЧИСТЫ, И ЗАЯВЛЕННЫЕ ЧИСЛА ПОДКРЕПЛЕНЫ ФАЙЛАМИ
        файл                            точек  n   вне куба  коллинеарных
        witness_n5_40_uniform...          40   5      0         0
        n6_64_first_solver.txt            64   6      0         0
        witness_n7_71.txt                 71   7      0         0
        witness_n7_first_solver.txt       72   7      0         0
        n7_warm_first_solver.txt          73   7      0         0   <- a(7) >= 73
        witness_n8_89.txt                 89   8      0         0
        n8_warm_first_solver.txt          89   8      0         0
        n8_warm93_first_solver.txt        93   8      0         0   <- a(8) >= 93
   Проверка: все C(m,3) тройки, векторное произведение в целых числах; отдельно проверено,
   что точки различны и лежат внутри куба.

3. ЧЕГО ЭТА СВЕРКА НЕ ПОДТВЕРЖДАЕТ, И ЭТО НАДО СКАЗАТЬ ПРЯМО
   Данные 1, 8, 16, 28, 40, 64 суть ТОЧНЫЕ значения, то есть содержат ВЕРХНЮЮ границу.
   Свидетель даёт только нижнюю. Верхние границы стоят на исчерпывающем переборе и на
   сертификатах DRAT, проверенных внешним checker'ом, — их эта сверка НЕ повторяла.
   Подтверждено здесь: нижние границы 40 при n=5, 64 при n=6, 73 при n=7, 93 при n=8.

4. ОТДЕЛЬНО О ПОЛИТИКЕ. Она запрещает «using AI to generate the full text of comments» и
   «pasting AI-generated text into the Pink Boxes as responses to editorial queries».
   Нынешний блок COMMENTS в черновике написан ИИ и потому требованию не отвечает;
   ответ редактору должен быть написан автором. Замечание Эндрю Хоуройда («большую часть
   комментариев следует удалить») ведёт к тому же исходу с другой стороны.
   Замечания Мишеля Маркуса: перенести Theta(n^2) в FORMULA и раскрыть нотацию (проще
   написать «существуют c1, c2 > 0 с c1*n^2 <= a(n) <= c2*n^2, Pór and Wood»); ссылки
   расставить по алфавиту (P после K).
