## Сессия 1 (19.08, 01:00–02:30 WITA) — где сидит потеря Θ(p)?
Факты на входе: α(P₋₁) = 3(p−1)+5/6 (11…19), теорема ≤ 4(p−1) − 4m₈ ≈ 3.67(p−1), LP(1) ≈ 3.45 нелокально; орбитные блоки 4×4 (≤8/блок,
истина ≈6/блок); периодическая модель ≤ 3(p−1).
Гипотеза H1: потеря локальна — уже пары/тройки орбитных блоков конфликтуют.  ПРОВЕРЕНО (`slack/block_pairs.py`, p=11…19): пары НИКОГДА не
конфликтуют (max = 16 для всех пар), тройки — почти никогда (потеря 1 у 1 из 56 троек при 17, у 4 из 84 при 19).  ⇒ H1 ложна: потеря
глобальна (высшего порядка).  Следствие: локальные гаджеты (в т.ч. ранга 2 на 2–3 блоках) T1 не дадут.
Гипотеза H2: потеря появляется как «порог» при m ≈ c·(число блоков) и дальше растёт линейно (тогда возможен аргумент через плотность/
подсчёт), либо растёт гладко с m (тогда — усреднение по подмножествам).  ПРОВЕРКА: `slack/block_subsets.py` (loss(m) для всех m при p=19).
ПРОВЕРКА H2 (`slack/block_subsets.py`, p=19): loss(m) = 0 при m ≤ 3 (кроме 3 троек с потерей 1), при m=4: 50 подмножеств без потери,
9 с потерей 1, ОДНО с потерей 8 ({3,4,5,6}: максимум 24 из 32); m=5: средняя потеря 1.2 (0…8).  Потеря‑8 гаджет = два «обратных»
блока‑пары: 1/4 ≡ 5, 1/3 ≡ −6 — классы с обеими малыми координатами (3,−6),(6,−3),(4,5),(5,4): их копии сидят у центрального креста бокса,
где прямые малых наклонов густы.  Гипотеза H3: сильные гаджеты живут только при малых |X(a)|,|X(1/a)| (их O(√p)), т.е. дают o(p) потери;
основная потеря (по 1 на большинство блоков в оптимумах при 17/19, данные первого) — «размазанная».  Проверка на p=23 (все 4‑подмножества)
запущена (`bench/block4_p23.log`).
Итог сессии 1 (02:30 WITA): (i) потеря глобальна — пары/тройки блоков не конфликтуют; (ii) третий (B.11): IP(1) = LP(1) − O(1) при
p ≤ 59 ⇒ ЛЮБЫЕ локальные неравенства (любого ранга) на строках/столбцах/±1(±2)-прямых не могут дать ниже ≈3.45(p−1): T1 требует прямых всех
наклонов; (iii) сильные 4‑блочные гаджеты существуют, но, по‑видимому, только у центрального креста.  Значит: путь к T1 — глобальный
(псевдослучайность коллинеарных троек всех наклонов для плотных S) — исследовательская задача без готового инструмента; путь «покрытия»
исчерпан на 11/3 (чисто) / 3.45 (LP).
