# Репликация Reverse Finding 1 ресёрча 8 (гипотеза A «без Бёрджесса») — первый солвер, 2026-08-20
Инструмент: `slack/conjA_replicate.py` (моя реализация с нуля: перечисление семейств, F₂‑структура присутствия, минимум по всем 2^m паттернам,
эмпирический минимум по простым).

## 1. Что воспроизвелось ТОЧНО
Семейства z = s₁ + i s₂ (примитивные, 1 ≤ s₁ ≤ s₂, σ := s₁+s₂ ≤ σ₀), присутствие ⇔ χ_p(N) = +1, N = s₁²+s₂²; биты присутствия определяются
символами Лежандра простых, входящих в N в НЕЧЁТНОЙ степени ⇒ точка F₂^m.
   σ₀ = 16: **40 семейств, m = 18**;  σ₀ = 18: **51, m = 22**;  σ₀ = 20: **64, m = 26** — совпадает с таблицей ресёрча до единицы.
Единственное безусловно присутствующее семейство — (3,4), N = 25 (пифагорово) ✓.

## 2. Числа (воспроизведены в пределах 3 %)
При весе **1/N** и c₀ = 24.4 (калибровка ресёрча):
   минимум по всем 2^m паттернам: **8.46 / 9.14 / 9.98** при σ₀ = 16/18/20 (ресёрч: 8.74 / 9.37 / 10.11);
   эмпирический минимум по 1000+ простым в [200, 8000]: **8.77 / 9.67 / 10.69** (ресёрч: 10.88 при σ₀ = 20; у меня 10.69 при p = 4493).
Порядок величин, монотонность по σ₀ и соотношение «теоретический минимум < эмпирический» — всё воспроизводится.

## 3. НАХОДКА: результат чувствителен к нормировке, и это ровно тот незакреплённый параметр
§21 формулирует счёт как **N_box ≥ c₀·p/(s₁+s₂)²**, то есть вес 1/σ²; но воспроизводящиеся числа отвечают весу **1/N = 1/(s₁²+s₂²)**.
Эти веса различаются множителем (s₁+s₂)²/(s₁²+s₂²) ∈ [1, 2] (в среднем ≈ 1.6 на нашем списке). Если взять БУКВАЛЬНУЮ форму §21 с тем же c₀ = 24.4:
   минимум по паттернам: **5.31 / 5.70 / 6.15** — НИЖЕ требуемого порога ≈ 9 (и порог ≈ 5.84 из §23 перекрывается только при σ₀ = 20).
Разрешение противоречия: c₀ обязан калиброваться тем же весом, каким используется; c₀ = 24.4 ресёрча очевидно идёт с 1/N. Тогда утверждение
внутренне непротиворечиво — НО запас над порогом тонкий: 9.14 при σ₀ = 18 и 9.98 при σ₀ = 20, то есть 2–11 %, что целиком внутри неопределённости
самого c₀ (это и есть пункт (1) списка «что надо закрепить» самого ресёрча).

## 4. Вывод репликации
(a) Структурная часть — **подтверждена**: сведение «конечная проверка + классические счёты Клоостермана, без Бёрджесса» корректно как схема;
    множество паттернов действительно конечно (m ≤ 26), минимум по нему вычислим точно, и он положителен из‑за мультипликативности.
(b) Численная часть — **воспроизводится**, но её вывод («порог ≈ 9 перекрыт») держится на калиброванной константе c₀ с запасом ≈ 2–11 %.
(c) Следовательно: до строгого закрепления c₀ (явный счёт Клоостермана с кратностями лифтов 1–4 и подтроек ≤ 4) утверждение «гипотеза A
    сводится к конечной проверке» имеет статус «схема верна, число не гарантировано». Это НЕ отменяет ценности находки: она переводит задачу
    из аналитической (Бёрджесс) в вычислительно‑конечную, но закрывать её надо аккуратно.
(d) Практическое следствие для программы: увеличение σ₀ помогает монотонно (минимум растёт), так что при закреплённом c₀ достаточно взять σ₀
    побольше: у меня минимум по паттернам растёт 8.46 → 9.14 → 9.98 при σ₀ = 16 → 18 → 20, то есть ≈ +0.75 на каждые +2 к σ₀ (m растёт до 26 —
    перебор 2^26 всё ещё мгновенный; σ₀ = 24–26 даст m ≈ 32–36, где нужен Уолш–Адамар вместо прямого перебора).
