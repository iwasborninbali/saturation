# Что делает кусок трудным: резкий порог по плотности, которую обязан дать остаток

Первый солвер, 2026-08-21. Найдено после того, как объяснение через израсходованную ёмкость слоя
было проверено вторым солвером и **не подтвердилось**: доля дроблений оказалась немонотонной по
расходу запаса, с выбросом 54 % в середине.

## Переменная

Для куска, зафиксировавшего `k` столбцов с `p` точками в них, остаток обязан дать `M − p` точек
на `49 − k` столбцах. Плотность остатка

    d = (M − p) / (49 − k),    при n = 7, M = 19 общая плотность 19/49 = 0.388

## Измерение: 395 дроблений и 21 757 закрытий

    d      закрытий  дроблений   доля дроблений
    0.29      3877        0          0.00 %
    0.31      3726        0          0.00 %
    0.33      4767        0          0.00 %
    0.35      1030        0          0.00 %
    0.36       877      148         14.44 %
    0.37       237      113         32.29 %
    0.38       107       72         40.22 %

**Порог резкий: ниже 0.35 не дробится ничего, выше — растёт быстро.**

## Это НЕ переодетая глубина

Внутри каждой отдельной глубины картина та же:

    глубина 5: 0.32 -> 0%   0.34 -> 0%   0.36 -> 18%
    глубина 6: 0.30 -> 0%   0.33 -> 0%   0.35 -> 0%   0.37 -> 37%
    глубина 7: 0.31 -> 0%   0.33 -> 0%   0.36 -> 28%  0.38 -> 3% (58 наблюдений)
    глубина 8: 0.29 -> 0%   0.32 -> 0%   0.34 -> 0%   0.37 -> 51%
    глубина 9: 0.30 -> 0%   0.33 -> 0%   0.35 -> 0%   0.38 -> 64%

Порог держится на всех глубинах и в одном месте. Единственное отклонение — 3 % при 0.38 на
глубине 7 на 58 наблюдениях; на порядок меньшая выборка, чем у прочих клеток.

## Смысл

Кусок труден ровно тогда, когда **зафиксированные столбцы взяли МЕНЬШЕ точек, чем причитается по
средней плотности**, и остатку приходится быть плотнее целого. Поскольку 0.388 — почти предел
возможного (ёмкость слоя 3 на 7 столбцов даёт 0.43), требование быть плотнее среднего сразу
подводит кусок к границе выполнимости, и решателю приходится искать, а не распространять.

## Следствие, которое можно применять

Трудность **предсказуема по имени куска** до всякого запуска решателя: плотность остатка считается
из индексов подмножеств арифметикой. Значит очередь можно упорядочивать не «обратным порядком имён»
(что мы делали как приближение), а **прямо по плотности** — и дробить сразу те, что выше порога,
не тратя на них срок решателя.

Ограничение: порог измерен на одной задаче (A280537, n = 7, M = 19). Переносить на другие n и M
без повторного измерения нельзя — но сама величина определена для любых, и мерить её дёшево.

# Независимая проверка вторым солвером и уточнение: порогов ДВА

Дописано 2026-08-21 02:20 WITA. Проверка сделана ПРЕЖДЕ внедрения, на отдельном наборе данных, собранном
на других машинах и по другим ветвям дерева.

## Подтверждение

    плотность:  <=0.34   0.35    0.36    0.37    0.38    0.39
    закрыто:      4704     249     345     140      25      18
    дроблений:       0       3       8      26      35      12
    доля:        0.00%   1.19%   2.27%  15.66%  58.33%  40.00%

**Ниже 0.35 не раздробился ни один кусок из 4704.** Граница встала ровно там же, где у первого
солвера, на независимом наборе.

## Это не переодетая глубина — проверено и здесь

Внутри каждой глубины отдельно:

    глубина  5: 0.32->0%  0.34->0%  0.36->12%
    глубина  8: 0.32->0%  0.34->0%  0.37->44%
    глубина  9: 0.30->0%  0.33->0%  0.35->3%   0.38->52%
    глубина 11: 0.29->0%  0.32->0%  0.34->0%   0.37->6%

Порог стоит на месте при любой глубине. Значит переменная — плотность, а не глубина.

## УТОЧНЕНИЕ: порог трудности и порог «дробить сразу» — РАЗНЫЕ величины

Первый солвер предложил один порог. Их два, и путать их дорого.

«Ниже 0.35 не дробится ничего» отвечает на вопрос ЧТО ТРУДНО.
«С какой плотности выгодно пропускать решателя» — другой вопрос, и ответ на него иной.

Ожидаемая выгода от немедленного дробления: экономия = (доля дроблений) x (сэкономленный срок
решателя); потеря = (доля закрытий) x (стоимость лишнего дробления с его 64 детьми).
При сроке 120 с, среднем закрытии 5 с, дроблении 5.5 с и 64 детях по ~0.5 с:

    d=0.35:  экономия  1.4 с | потеря 37.1 с | ЧИСТО  -35.7 с
    d=0.36:  экономия  2.6 с | потеря 36.6 с | ЧИСТО  -34.0 с
    d=0.37:  экономия 18.0 с | потеря 31.6 с | ЧИСТО  -13.6 с
    d=0.38:  экономия 67.1 с | потеря 15.6 с | ЧИСТО  +51.5 с
    d=0.39:  экономия 46.0 с | потеря 22.5 с | ЧИСТО  +23.5 с

**При 0.37 дробится лишь 16 %, и пропуск решателя теряет больше, чем экономит.** Выгода
начинается с 0.38. В код поставлено 0.38, иначе мы платили бы лишним дроблением за каждые
пять кусков из шести, которые закрылись бы сами.

## Проверка смысла на трёх случаях

    case_00000_s000_s000_s000  (одни пустые подмножества)  d=0.422  -> дробить сразу
    case_00000_s007_s002                                    d=0.370  -> решать
    case_00000_s000_s063_s063  (одни тройки)                d=0.289  -> решать

Порог отделяет ровно ту «пустую» ветку, которую мы весь вчерашний день ловили эмпирически, —
и отделяет её ПО ИМЕНИ, до запуска решателя.

## Внедрено

`slack/targets/sos_second.sh`: плотность считается из имени куска, и при d >= 0.38 кусок идёт
на дробление без запуска решателя. Под условием n == 7, потому что порог измерен для n=7, M=19.

## Что из этого следует шире находки

Полдня мы пользовались обратным порядком обхода и объясняли его тем, что пустое подмножество
наименее ограничено. Объяснение было верно ПО НАПРАВЛЕНИЮ и неверно ПО ВЕЛИЧИНЕ: плотность
различает «взять точку рано» и «взять точку поздно», а порядок индексов не различает — и именно
поэтому приближение работало, но не показывало, где перестанет.

> **Работающий приём стоит доводить до величины, которую он приближает.** Пока этого не сделано,
> не видно ни границ его применимости, ни того, чем его заменить, когда он откажет.

Та же мысль в другом виде: у первого солвера гипотеза про израсходованную ёмкость слоя ОТКАЗАЛА
(немонотонность, выброс 54 %), и это указало направление к верной переменной. Отвергнутая
гипотеза, проверенная честно, сделала больше, чем подтверждённая.

## Применение: оценка БЛИЖАЙШЕЙ ВОЛНЫ работы (2026-08-21 02:40 WITA)

Порог даёт то, чего у нас не было: оценку предстоящей работы ИЗ ИМЁН, без запуска решателя.

На момент замера непосчитанных детей 518:

    закроются сами (d < 0.35)      260   50.2 %   — ниже порога не дробился НИ ОДИН из 4704
    трудные (0.35 .. 0.38)         189   36.5 %   — решать, но дробить не спешить
    дробить сразу (d >= 0.38)       69   13.3 %   — решатель на них тратить незачем

Шестьдесят девять дроблений добавят примерно 4400 детей на следующем уровне.

ЧТО ЭТО ЕСТЬ И ЧЕМ НЕ ЯВЛЯЕТСЯ. Это оценка ОДНОЙ волны, а не остатка до конца: следующую можно
будет посчитать, только когда станут известны плотности этих 4400. Складывать волны в срок
нельзя — мы этого не делаем сознательно, потому что за два дня трижды принимали устойчивую
скорость за предсказание.

ПРОВЕРЕНО, ЧТО ПЛОТНОСТЬ — МЯГКИЙ ПРЕДСКАЗАТЕЛЬ, А НЕ ДОКАЗАТЕЛЬСТВО. Столбец несёт до трёх
точек, значит невыполнимость по чистому счёту наступает при d > 3. Наши значения лежат в
0.28..0.43 — далеко от границы. Связывает по-настоящему ёмкость СЛОЯ (3 точки на 7 столбцов),
а не столбца, и потому «d ниже 0.35» есть эмпирическое наблюдение на 4704 кусках, а не теорема.
Пользоваться им как эвристикой планирования можно; как доводом в доказательстве — нельзя.
