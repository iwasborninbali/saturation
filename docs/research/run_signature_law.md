## 1. Редукция: класс ребра — это сумма и разность корней
Вершина графа соседей — это t = d²/4 (КВ), ребро (t, t+1) существует ⇔ t и t+1 оба КВ ([166]). Пусть u_s — любой из двух корней √s. Тогда
H(1)-пара ребра (t, t+1) — это в точности
   a = u_t + u_{t+1},   1/a = u_{t+1} − u_t     (проверка: a·(1/a) = u_{t+1}² − u_t² = 1 ✓),   a − 1/a = 2u_t = d.
Пара «делит центр» ⇔ X(a)·X(1/a) < 0. Поэтому вдоль серии КВ t, t+1, …, t+k−1 (k вершин, k−1 рёбер) определён БИТ
   ξ_i := [ X(u_i + u_{i+1})·X(u_{i+1} − u_i) < 0 ],  i = 1..k−1,
инвариантный к выбору знаков корней (замена u_i → −u_i меняет a ↔ −1/a, произведение X(a)X(1/a) не меняется).
Типы вершин (по лемме partners: соседняя группа видит ту же пару «с флипом»):
   внутренняя вершина между рёбрами i−1 и i:  (8,4,4) ⇔ ξ_{i−1} = 0 и ξ_i = 1;  (6,6,2,2) ⇔ ξ_{i−1} = 1 и ξ_i = 0;  иначе (7,5,3,1);
   левый конец: (4,2,2) ⇔ ξ_1 = 1, иначе (3,3,1,1);   правый конец: (4,2,2) ⇔ ξ_{k−1} = 0, иначе (3,3,1,1).
(Согласованность подтверждается «зоопарком» коллеги: в `comp_savings.json` встречаются ровно те сигнатуры, которые допускает это правило.)

## 2. Локальный закон и ТОЧНОЕ тождество
Локальный закон (Вейль/Бомбьери на цепочке коник u_{i+1}² = u_i² + 1, как в prop m8asym / Lemma FE): позиции v_i := X(u_i)/p ∈ (−½, ½) асимптотически
НЕЗАВИСИМЫ и равномерны (и независимы от условий «квадрат/не квадрат», задающих серию, — куммерова независимость).
**Тождество.** Для v, w ∈ (−½, ½): знак c(x) центрированного представителя совпадает со знаком sin 2πx, и
   sin 2π(v+w) · sin 2π(w−v) = ½ [ cos 4πv − cos 4πw ],
поэтому   **ξ(v, w) = 1 ⇔ cos 4πv < cos 4πw ⇔ g(v) > g(w),  где g(x) := min(|x|, ½ − |x|)** — расстояние x до ближайшей точки {0, ±½}.
Для v равномерного g(v) равномерно на (0, ¼) (4‑к‑1 линейное отображение). Следовательно:
**цепочка (ξ_1, …, ξ_{k−1}) — это в точности множество СПУСКОВ последовательности k независимых равномерных величин g(v_1), …, g(v_k).**
Отсюда замкнутая формула для плотностей сигнатур:
   **P(ξ = ε) = β_k(S)/k!,  S = {i : ε_i = 1},  β_k(S) = число перестановок [k] с множеством спусков РОВНО S** (числа Эйлера/бета‑числа спусков).
Проверено двумя независимыми способами: (i) точный трансфер‑оператор на кусочно‑полиномиальных плотностях в рациональной арифметике
(`slack/sig_density.py`) — совпадение при всех длинах ≤ 5 (0 расхождений); (ii) Монте‑Карло 2·10⁶ (0 расхождений в самом тождестве ξ = [g(v) > g(w)]).
Примеры: P(1) = ½; P(00) = P(11) = 1/6, P(01) = P(10) = 1/3 (⇒ закон (⅓,⅓,⅓) типов §24 — как частный случай!); P(000) = P(111) = 1/24,
P(001) = P(011) = P(100) = P(110) = 1/8, P(010) = P(101) = 5/24; вообще P(все 1) = 1/(k)!… (для k вершин 1/k!).

## 4. Константа
Плотность серий длины k (максимальных) = 2^{−(k+2)}·p + O(k√p) (классика, Вейль), плотность сигнатуры внутри — β_k(S)/k!, и эти два независимы
(куммерова независимость). Итог:
   **экономия/p = Σ_{k ≥ 2} 2^{−(k+2)} Σ_{S ⊆ [k−1]} (β_k(S)/k!) · sav(сигнатура(S, k))**,   α(P₋₁) ≤ (4 − экономия/p + o(1))(p−1),
где sav — точная (целочисленная) экономия компоненты по сигнатуре (таблица второго солвера). С его текущей таблицей (46 сигнатур с учётом разворота):
   k ≤ 3: 0.1875 ⇒ 3.8125;  k ≤ 4: 0.3151 ⇒ 3.6849;  k ≤ 5: 0.4150 ⇒ 3.5850;  k ≤ 6: 0.4638 ⇒ 3.5362;  k ≤ 7: 0.4779 ⇒ 3.5221
(для k ≥ 6 часть сигнатур в таблице отсутствует — суммарная плотность нехватки 0.0008–0.0013 на длину, поэтому истинные значения чуть ниже;
сравнение с эмпирическими усечениями коллеги: L ≤ 5: 3.595 (модель 3.585), L ≤ 7: 3.480 (модель ≤ 3.522 с недостающими сигнатурами)).
Полная константа = среднее по цепи: если DP коллеги даст sav(S) конечным автоматом, то экономия/p = Σ_k 2^{−(k+2)}·E[sav | k] считается точно
(совместный трансфер‑оператор: состояние = (позиция g на (0,¼), состояние DP); ведущее собственное значение — та же машина, что здесь).
