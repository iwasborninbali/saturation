# Часовой диагностический аудит кандидата E (гипотеза Эрдёша–Штрауса) — 2026-08-20

Проведён по рекомендации ресёрча №10 («E первый только как часовой аудит, полный прогон НЕ авторизован»).
Код: `slack/es/es_check.c`. Вердикт получен, полный прогон не рекомендуется.

## Что сделано
Реализована проверка «для данного n найти x, y, z с 4/n = 1/x + 1/y + 1/z» перебором x ∈ (n/4, 3n/4] и, для каждого x,
поиском разложения остатка. По мультипликативности достаточно проверять простые n.

## Результаты калибровки
- Все простые до 20 000: **0 отказов** ✓ (согласуется с известным статусом гипотезы).
- Распределение трудности: **2112 из 2262 простых решаются с ПЕРВОЙ пробы x**, ещё 150 — за 2–4 пробы, худший случай 6 проб (n = 1201).
  Причина: при n ≡ 3 (mod 4) значение a = 4x − n равно 1 при x = (n+1)/4, и решение тривиально (y = b+1, z = b(b+1)).
  То есть «трудных» n мало, и трудность их не в числе проб x.

## Найденная ошибка алгоритма (главный результат аудита)
Наивный внутренний цикл по y ЛИНЕЕН по b/a, где b = n·x, a = 4x − n. При малом a (а он мал именно в интересных случаях)
это ~n²/16 итераций: при n = 10⁶ прогон не завершился за 97 с. **Наивная схема непригодна начиная с n ≈ 10⁵.**
Правильная схема — тождество **(a·y − b)(a·z − b) = b²**: перебирать делители b², а не значения y. Тогда стоимость на одно n
определяется числом делителей b², а не величиной b/a. Это стандартный приём, и без него любая оценка стоимости бессмысленна.

## Вердикт по стоимости (критерий C2)
Даже с правильной схемой связывающее ограничение — **не стоимость одного n, а их количество**: чтобы превзойти опубликованный
рубеж 10¹⁸, надо перебрать π(10¹⁹) ≈ 2·10¹⁷ простых. Одно только их порождение (решето до 10¹⁹) на порядки за пределом наших
~65 ядер. Опубликованные проверки такого масштаба используют НЕ поштучный перебор, а покрывающие сравнения: почти все классы
вычетов закрываются полиномиальными тождествами, и индивидуально проверяется лишь разреженный остаток.

**Следствие:** интересное в этой задаче — не вычисление, а структура покрытия (какие классы закрыты тождествами и что остаётся).
Это работа по теории, а не по счёту, то есть **вне нашего профиля**. Кандидат E закрывается по C2.

## Что взято на будущее
1. Приём «(ay−b)(az−b) = b²» — типовой для уравнений с единичными дробями; пригодится, если появится похожий кандидат.
2. Урок метода: **сначала измерить стоимость на растущих n, потом писать вывод.** Наивная реализация выглядела быстрой
   при n ≤ 2·10⁴ и стала непригодной при 10⁶ — ровно предасимптотическая ловушка, но уже в стоимости, а не в результате.
