## Структура задачи (наш вклад в постановку)

Четыре точки компланарны ⟺ лежат в общей плоскости. Плоскость, содержащая ≤ 3 узла решётки, запретить
ничего не может. Отсюда

> S ⊆ [n]³ допустимо ⟺ для КАЖДОЙ плоскости P с ≥ 4 узлами решётки: |S ∩ P| ≤ 3.

Это в точности форма «прямая, ёмкость 2» из no-three-in-line, только ёмкость 3, поэтому весь наш
инструментарий переносится. Следствие, используемое как граница ветвления: слой z = k сам есть
плоскость (n² ≥ 4 узлов при n ≥ 2), значит в каждом слое не более трёх точек и

> **a(n) ≤ 3n.**

Проверка по всем опубликованным членам: 5 ≤ 6, 8 ≤ 9, 10 ≤ 12, 13 ≤ 15, 16 ≤ 18, 18 ≤ 21, 20 ≤ 24.

### Пойманная ошибка (записана, потому что она типовая)

Первая версия `plane4.c` перечисляла плоскости по коэффициентам с |a|,|b|,|c| ≤ n−1 и дала n = 4 → **11**
вместо 10. Нашла встроенная проверка свидетеля определителями: в нём оказались две компланарные четвёрки.
Причина — нормаль плоскости есть векторное произведение разностей, её координаты доходят до 2(n−1)²;
плоскость 6x − 3y − 4z = 0 в список не попадала, терялась четверть всех плоскостей (1314 вместо 2094).
Исправление: плоскости перечисляются по тройкам узлов с дедупликацией — потерять нельзя по построению.
Проверка свидетеля встроена в программу: при ненулевом числе компланарных четвёрок она отказывается
печатать ответ.

## C2 — аудит стоимости (в работе)

Инструмент: стратифицированный оценщик размера дерева. Чистая оценка Кнута на этом дереве **непригодна**:
при n = 6 среднее по 20 000 спусков на 89 % состояло из одного спуска (медиана 2.4·10⁹ против среднего
1.37·10¹⁴). См. ловушку 4 в `SELECTION.md`. Стратифицированная версия откалибрована по точному дереву
n = 4: **1 771 000 против точных 1 769 732 (0.1 %)**, устойчиво при глубинах страты 2, 3, 4.

Скорость: `plane4.c` — 1.4·10⁶ узлов/с (поддержка плоскостей дорога); `no4coplanar.c` — 12.3·10⁶ узлов/с.

Решающее вычисление называется ЗАРАНЕЕ: **полный перебор [7]³ с затравкой best₀ = 18**; исход
«MAX = 18» доказывает a(7) ≤ 18 и вместе со свидетелем даёт a(7) = 18; исход «MAX = 19» опровергает
запись OEIS. Оба исхода публикуемы, и второй сильнее.
