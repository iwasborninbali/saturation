# Световые координаты, массовые оболочки и «суперпозиция»: идея хозяина, переведённая в нашу структуру (первый солвер, 19.08, вечер)
## 1. Словарь (точный, не метафорический)
Положим u = x − y, v = x + y — **световые координаты** (это ровно наши r₊, r₋). Тогда
   xy = c  ⟺  v² − u² = 4c,
то есть **гипербола H(c) — это массовая оболочка «интервала» 4c**, а прямые наклона ±1 — **световые лучи** (u = const, v = const).
Отсюда сразу: (i) весь наш блочный анализ живёт в световых координатах — граф соседей строился по t = r₊²/4, а рёбра соединяли оболочки,
интервалы которых различаются на 4 (соседние оболочки!); (ii) «буст» (x, y) ↦ (λx, λ⁻¹y) сохраняет каждую оболочку — это группа Лоренца
формы v² − u², порядка p−1; она перемешивает представителей в коробке (искажение координат), но сам вычетный набор оставляет на месте.
## 2. «Точки в суперпозиции» = объединение нескольких оболочек
Если положение точки не фиксировано до вычисления, то каждому вычету x отвечает НЕСКОЛЬКО возможных y (по одному на оболочку). Пара
гипербол = две оболочки ±4; **четвёрка** = ±4, ±4k. «Временное нарушение принципов» = в объединении заведомо много коллинеарных троек;
«диффузия» = процесс, оставляющий только допустимое подмножество.
## 3. Первый результат (ТОЧНЫЙ, CP-SAT): четвёрка СУЩЕСТВЕННО больше пары
   p = 11: пара 32 = 1.455·N (N = 2p), четвёрка (±1, ±2) **≥ 37 = 1.682·N** (верхняя граница решателя 40);
   p = 13: пара 40 = 1.538·N, четвёрка **≥ 44 = 1.692·N** (граница 48).
Для сравнения: HJSW (одна гипербола) = 3(p−1) ≈ 1.5·N — рекорд алгебраических конструкций в окне 2p×2p. То есть при малых p объединение
четырёх оболочек ощутимо ПРЕВОСХОДИТ 3/2·N. Если это сохраняется асимптотически, то (а) есть алгебраическая конструкция лучше HJSW в окне,
(б) сильная форма нашей гипотезы G («объединение ≤ m кривых степени ≤ d не бьёт 3/2») ОПРОВЕРГАЕТСЯ. Оговорка: при p = 11, 13 поправки O(1)
велики (у пары 1.455 и 1.538 при истинном пределе 1.5), поэтому нужен тренд по p — считается.
## 4. «Фотоны»: световые ходы как окрестность поиска
Метафора «кванты, живущие только на скорости света» переводится в алгоритм: элементарный ход — сдвиг точки ВДОЛЬ светового луча
(u = const или v = const) в другую точку объединения, возможно на ДРУГОЙ оболочке (переход между оболочками ровно и происходит по световым
направлениям: (x+t)(y+t) = c + t(x+y+t)). Отжиг с такими ходами (`slack/null_search.py`) при p = 13 находит точный оптимум пары (40)
и 41 для четвёрки за секунды. Диффузионный сэмплер в чистом виде (`slack/diffusion_sampler.py`: амплитуды u ∈ [0,1], мягкая проекция
Σ_ℓ u ≤ 2, шум + «схлопывание») слабее (35/36) — как самостоятельный оптимизатор он уступает световому отжигу, но полезен как инициализация.
