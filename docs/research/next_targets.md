## Дополнение 05:10 WITA — цель G (по тексту задачи 72 Грина)
Грин (комментарий к Problem 72, версия 01.2026): «It is possible that any no-three-in-a-line subset of [N]² is either small, or has a large subset which
reduces (mod p) to a set of points on a curve in F_p². It might be interesting to formulate a precise conjecture of this type and see whether it can be
used to show that the construction of [HJSW] is optimal. I would find this a lot more convincing than the heuristic given by Guy and Kelly.»
Наши результаты — ровно кусок второй половины этой программы: в окне 2p×2p коники дают ≤ 3(p−1) (только сдвинутые гиперболы достигают), пара
гипербол ≤ 11/3(p−1). Кандидат‑теорема G: «для любой кривой ограниченной степени d над F_p множество точек окна [0,2p)², сводящееся mod p к кривой,
без трёх на прямой имеет ≤ (3+o_d(1))p точек, с равенством только для сдвинутых гипербол» — «алгебраические конструкции в естественном окне не бьют 3/2».
Данные (`scratchpad/tricount.py`, `winscan.py`): кубики y = x³, x³+x, эллиптические при p ≤ 101 несут 5–7.6 коллинеарных троек НА ТОЧКУ (гипербола: 0.7),
прямые до 6 точек; точные максимумы при p = 11…19 — 0.37–0.64 от кандидатов против 0.75 у гиперболы (со сканом окон при 11, 13). Т.е. для d = 3 утверждение
верно с большим запасом численно, но доказательство требует описать богатые прямые поднятой кубики (для гиперболы это были только наклоны ±1 — «чудо»
окна HJSW). Шанс на общую теорему за неделю < 15 %; частные (графики y = f(x)?) — возможно. Ценность: прямой ответ на пожелание Грина в комментарии к
задаче из списка; это заметнее любой полировки константы. Предлагаю обсудить утром как альтернативу C.
