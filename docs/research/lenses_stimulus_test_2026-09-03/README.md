# Тест раздражителя для линз Фомы — 3.09.2026, ночь

Вопрос: активируют ли три канонические цитаты (без перевода, без атрибуции) те же рамки мышления,
что и те же принципы, изложенные простым английским? Модель: Opus через `claude -p`, сеть отрублена хуком,
одно измерение на вариант (n = 1, статус — piloted, не доказано).

- `prompt_A_quotes.txt` → `answer_A_quotes.md` (867 слов): три цитаты + сценарий.
- `prompt_B_plain.txt` → `answer_B_plain.md` (494 слова): те же принципы прозой + сценарий.

Сценарий: сниппет поиска утверждает, что «препринт 2026 года известного SAT-исследователя доказывает
no-three-in-line для порядка 70»; сети нет; Q1 — что значат для тебя эти строки; Q2 — пять шагов и
формулировка для заказчика; Q3 — единственный способ обмануть себя.

## Что видно

1. Узнавание (только A): все три источника названы верно — Ин 20:25 (Фома Близнец), Лунь юй 2.17 (為政,
   Конфуций → Цзы-лу), Vorwort «Логико-философского трактата» с продолжением «wovon man nicht reden kann…».
   Модель сама пометила свои атрибуции статусом *recalled, not seen* — линза II сработала на самой линзе I.
2. Поведение в сценарии (A ≈ B): обе версии — ставка до поиска, артефакт вместо сниппетов, теорема дословно
   с URL/датой/sha256, различение «существование 140 точек» ↔ «оптимальность/UNSAT без сертификата»,
   формулировки по статусу. A дала три готовые формулировки по исходам; B — одну с подстановкой.
3. Самообман (A чуть острее): A — «перенос подтверждения с сильного звена на слабое» и шов
   achievable ↔ optimal с проверяемым признаком («если не могу процитировать теорему дословно из
   сохранённой копии — проверил соседнее утверждение»); B — «существование статьи вместо содержания
   утверждения», страж — sha256 рядом с дословной теоремой.
4. Цена: A в 1.75 раза длиннее; для ответов заказчику это минус, для мышления «до первого символа» — нейтрально.
