# Лемма о размахе по дугам (arc-imbalance lemma) — ингредиент (a) теоремы C

*первый солвер (Hetzner/linux-12c), 2026-08-19 ~00:00 UTC; по запросу THREAD[115]. Численная проверка: `slack/arc_imbalance.py`,
`slack/arc_imbalance_k.py`, лог `slack/verification/arc_imbalance.txt`.*

## 0. Обозначения (ровно как в `slack/cycle_stats.py::specials`)

p простое, k ∈ F_p^*, k ≠ 1 (и p ∤ k(k−1)). X(u) ∈ (−p/2, p/2) — представитель u mod p; h = (p−1)/2. Склон σ ∈ {+1, −1}.
Пара на H(c) (c ∈ {1,k}) склона σ с ключом d: {a, −σc/a}, где a − σc/a ≡ d. Ключ d даёт на H(1) не более одной пары
(корни a² − d a − σ = 0) и на H(k) не более одной (корни b² − d b − σk = 0). **8‑группа** склона σ с ключом d: обе пары
существуют и двухэлементны (дискриминанты d² + 4σ и d² + 4σk — ненулевые квадраты), и выполнены оба условия
«разделённости»:
   s₁(a) := [sign X(a) ≠ sign X(1/a)]  при σ=+1,   s₁(a) := [sign X(a) = sign X(1/a)]  при σ=−1;
   s_k(b) := [sign X(b) ≠ sign X(k/b)] при σ=+1,   s_k(b) := [sign X(b) = sign X(k/b)] при σ=−1.
(Оба условия инвариантны относительно замены a ↦ −σ/a, b ↦ −σk/b, т.е. корректно определены на парах.)
κ_x **специален** (f_K(x)=1), если x лежит в H(1)-паре какой‑нибудь 8‑группы; μ_y специален (f_M(y)=1), если y лежит
в H(k)-паре какой‑нибудь 8‑группы. K := #{x: f_K(x)=1}, M := #{y: f_M(y)=1}.

**Факт 0.** Каждая 8‑группа содержит ровно 2 κ‑ и 2 μ‑класса, группы разных ключей одного склона не пересекаются, а
классы разных склонов не пересекаются: условия s₁ склонов +1 и −1 — взаимно дополнительны (разные знаки vs одинаковые),
то же для s_k. Следовательно
   f_K = f_K⁺ + f_K⁻,   f_M = f_M⁺ + f_M⁻   (без члена‑произведения),   K = M = 2·G₈   (точно).
(K = M точно — наблюдалось во всех расчётах: `cycle_stats`, таблицы ниже.)

Пусть k имеет порядок L в F_p^*, r := (p−1)/L. Цикл графа классов на смежном классе a₀⟨k⟩:
κ_{a₀k^j} → μ_{a₀k^{j+1}} → κ_{a₀k^{j+1}} → …, j mod L. Для дуги I ⊂ Z/L (отрезок последовательных j) положим
   W(I; a₀) := Σ_{j∈I} ( f_K(a₀k^j) − f_M(a₀k^{j+1}) )     — дисбаланс κ/μ‑специальных на дуге,
   Δ(a₀)   := W(Z/L; a₀) = #κ‑спец. − #μ‑спец. в смежном классе (полный оборот).
Размах блуждания на цикле = max_I W − min_I W ≤ 2·max_I |W(I; a₀)|.

## 1. Формулировки

**Лемма A (суммы характеров).** Существует абсолютная постоянная C такая, что для всех p, всех k с p ∤ k(k−1) и всех
нетривиальных мультипликативных характеров ψ группы F_p^*:
   | Σ_{x∈F_p^*} f_K(x) ψ(x) | ≤ C √p (log p + 3)⁴,   | Σ_{y∈F_p^*} f_M(y) ψ(y) | ≤ C √p (log p + 3)⁴.
Численно (ДПФ вдоль примитивного корня, p ≤ 2003, все ψ ≠ 1, все k из таблиц): max_ψ |Ŝ|/√p ∈ [1.2, 2.7] — оценка
даже без логарифмов (логарифмы в доказательстве — артефакт разложения «коробок»).

**Лемма B (размах по дугам).** С той же C, для всех k, всех смежных классов a₀⟨k⟩ и всех дуг I:
   (i)  |Δ(a₀)| ≤ 2C √p (log p + 3)⁴;   при примитивном k (r = 1) Δ = K − M = 0 точно;
   (ii) | W(I; a₀) − (|I|/L)·Δ(a₀) | ≤ 2C √p (log p + 3)⁴ (log L + 1);
   (iii) следовательно |W(I; a₀)| ≤ 2C √p (log p + 3)⁴ (log L + 2) ≪ √p log⁵ p равномерно по k, a₀, I,
        и размах блуждания (#κ − #μ) на каждом цикле ≪ √p log⁵ p.
Численно: размах ≤ 1.0·√p при p ≤ 2003 (обычно 0.2–0.6 √p), |Δ| ≤ 0.8 √p — см. §4.

## 2. Доказательство леммы A

Достаточно оценить Ŝ_K^σ(ψ) := Σ_x f_K^σ(x) ψ(x) для каждого склона (факт 0); разберём σ = +1, склон −1 отличается
только знаками (кривая C⁻ ниже). Обозначим d(x) := x − 1/x.

**Шаг 1 (явный вид).** f_K⁺(x) = 1 тогда и только тогда, когда: x² ≠ −1 (пара {x, −1/x} двухэлементна);
Q⁺(x) := x⁴ + (4k−2)x² + 1 — ненулевой квадрат в F_p (это (d(x)² + 4k)·x², дискриминант уравнения партнёра
b² − d(x) b − k = 0); s₁(x) = 1; s_k(b) = 1 для корня b уравнения партнёра (значение не зависит от выбора корня —
второй корень −k/b, а s_k инвариантно, см. §0).

**Шаг 2 (кривая партнёров).** Пусть C⁺: x·b² − (x² − 1)·b − k·x = 0 (аффинная, x ≠ 0). Точки над данным x: ровно 2,
если Q⁺(x) — ненулевой квадрат, 1 — если Q⁺(x)=0, 0 — иначе. Функциональное поле F_p(C⁺) = F_p(x, √Q⁺(x)):
Q⁺(x) = (x² − u₁)(x² − u₂), u₁u₂ = 1, u₁ ≠ u₂ ⇔ 16k(k−1) ≠ 0 — четыре различных корня ±√u₁, ±√u₂ ⇒ Q⁺ свободен от
квадратов, кривая абсолютно неприводима, её гладкая модель Ẽ⁺ — эллиптическая (род 1). Над x = 0 и x = ∞ (Q⁺(0)=1,
deg Q⁺ = 4 чётная) по два места; на них
   b ≈ kx (P₀⁺),  b ≈ −1/x (P₀⁻),  b ≈ x (P∞⁺),  b ≈ −k/x (P∞⁻);
   div(x) = P₀⁺ + P₀⁻ − P∞⁺ − P∞⁻,   div(b) = P₀⁺ + P∞⁻ − P₀⁻ − P∞⁺   (все кратности ±1).
Итак Σ_x f_K⁺(x)ψ(x) = ½ Σ_{P=(x,b)∈C⁺(F_p)'} B₁(x) B₂(b) ψ(x), где B₁(x) := 1[s₁(x)], B₂(b) := 1[s_k(b)], а штрих
означает исключение точек с Q⁺(x)=0 (≤4 значений x) и x² = −1 (≤2 значения): их вклад ≤ 6.

**Шаг 3 (коробки → аддитивные характеры).** s₁(x)=1 ⇔ (X(x), X(1/x)) лежит в одном из двух «квадрантов»
{X>0}×{X<0}, {X<0}×{X>0}; каждый множитель — индикатор интервала длины h в Z/p, 1_J(u) = Σ_m ĉ_J(m) e(mu/p),
|ĉ_J(m)| ≤ min(½, 1/(2p‖m/p‖)), Σ_m |ĉ_J(m)| ≤ log p + 3. Поэтому
   B₁(x) = Σ_{m₁,n₁} c¹_{m₁n₁} e((m₁x + n₁x⁻¹)/p),   Σ|c¹| ≤ 2(log p+3)²;
   B₂(b) = Σ_{m₂,n₂} c²_{m₂n₂} e((m₂b + n₂ k b⁻¹)/p), Σ|c²| ≤ 2(log p+3)².
Следовательно
   Ŝ_K⁺(ψ) = ½ Σ_{m₁n₁m₂n₂} c¹c² · T(ψ; f) + O(1),   T(ψ; f) := Σ_{P∈C⁺(F_p)'} ψ(x(P)) e(f(P)/p),
   f := m₁x + n₁x⁻¹ + m₂b + n₂kb⁻¹ ∈ F_p(Ẽ⁺).

**Шаг 4 (Бомбьери).** T(ψ; f) — смешанная сумма (мультипликативный характер функции x, аддитивный характер функции f)
по F_p‑точкам кривой рода 1. По теореме Бомбьери (Bombieri 1966, Thm 6; в форме Perret 1991 / Kowalski, «Exponential
sums over finite fields», Thm «Weil bound for mixed sums along curves»): если пучок L_ψ(x) ⊗ L_e(f) геометрически
нетривиален, то |T| ≤ (2g − 2 + n_tame + Σ_{полюсы f}(1 + ord)) √p, где n_tame — число нулей/полюсов x. Куммеров пучок
имеет ручной порядок ord ψ | p−1, пучок Артина–Шрайера — порядок p; их произведение тривиально лишь когда оба тривиальны.
L_ψ(x) нетривиален: x = c·hᵈ (d = ord ψ ≥ 2) невозможно, так как все кратности div(x) равны ±1. Итак ДЛЯ ВСЕХ f
(в том числе f = 0 и вырожденных f = hᵖ − h + const) |T(ψ; f)| ≤ C_B √p с абсолютной C_B (полюсы f — только среди
четырёх мест над x ∈ {0,∞}, порядка ≤ 1: 2g − 2 + 4 + 4·2 = 12; плюс O(1) на исключённые точки штриха и на
аффинность: C_B ≤ 20 с запасом). [Проверить точную константу кондуктора; на порядок √p это не влияет.]

**Шаг 5 (сложение).** |Ŝ_K⁺(ψ)| ≤ ½ · 2(log p+3)² · 2(log p+3)² · C_B √p + 6 ≤ 2C_B √p (log p+3)⁴ + 6.
Склон −1: кривая C⁻: x·b² − (x²+1)·b + k·x = 0, Q⁻(x) = x⁴ + (2−4k)x² + 1 — тот же дискриминант 16k(k−1), род 1, те же
дивизоры x и b с точностью до знаков; коробки — «одинаковые знаки». Итого |Ŝ_K(ψ)| ≤ 4C_B √p (log p+3)⁴ + 12.
Для f_M: та же кривая C⁺ (роли: y = b, партнёр a = x), сумма ½ Σ_{C⁺} B₁(x)B₂(b) ψ(b); L_ψ(b) нетривиален по div(b)
(кратности ±1). Те же оценки. ∎

## 3. Доказательство леммы B (дополнение по характерам ⟨k⟩)

Γ := ⟨k⟩ (порядок L), характеры Γ: χ_m(k^j) = e(mj/L). Для F: a₀Γ → C и дуги I:
   Σ_{j∈I} F(a₀k^j) = (1/L) Σ_{m mod L} F̂(m) Σ_{j∈I} e(mj/L),   F̂(m) := Σ_{j'} F(a₀k^{j'}) e(−mj'/L),
|Σ_{j∈I} e(mj/L)| ≤ min(|I|, 1/(2‖m/L‖)), откуда
   | Σ_{j∈I} F(a₀k^j) − (|I|/L) F̂(0) | ≤ (log L + 1) · max_{m≠0} |F̂(m)|.
Каждый характер χ_m группы Γ есть ограничение ровно r характеров ψ группы F_p^*, и для z ∈ F_p^*
(1/r) Σ_{ψ|Γ=χ_m} ψ(z) = χ_m(z)·1[z∈Γ]. Значит
   F̂(m) = (1/r) Σ_{ψ|Γ = χ_{−m}} ψ̄(a₀) Σ_{y∈F_p^*} F(y) ψ(y)   (F продолжено нулём),
и при m ≠ 0 все такие ψ нетривиальны ⇒ |F̂(m)| ≤ max_{ψ≠1} |Ŝ_F(ψ)|. Берём F = f_K и F(y) = f_M(k y)
(сдвиг j+1: Σ_{y} f_M(ky) ψ(y) = ψ̄(k) Ŝ_M(ψ) — модуль тот же). Лемма A даёт (ii).
Для (i): Δ(a₀) = F̂_K(0) − F̂_M(0) = (1/r) Σ_{ψ|Γ=1} ψ̄(a₀) (Ŝ_K(ψ) − Ŝ_M(ψ)); слагаемое ψ = 1 равно (K − M)/r = 0
(факт 0), остальные ≤ 2C√p(log p+3)⁴ по лемме A. При r = 1 остаётся только ψ = 1 и Δ = 0 точно. (iii): W = (|I|/L)Δ +
остаток, |I|/L ≤ 1. ∎

Замечания. (1) Всё равномерно по k — порядок k входит только через log L ≤ log p, что согласуется с численно
плоским max_ψ|Ŝ|/√p ≈ 2 для всех k. (2) Логарифмы: (log p)⁴ от четырёх коробок можно снизить до (log p)² по Вааалеру
(Erdős–Turán–Vaaler для двумерных ящиков) — не нужно. (3) Уровень арифметики: как и предсказано в §26a, условие
партнёра живёт на эллиптической кривой C^±, поэтому здесь Бомбьери (уровень кривых), а не Клоостерман; но благодаря
нетривиальности L_ψ(x) никакого анализа вырождения аддитивной части не требуется — это делает лемму «дешёвой».
(4) Для теоремы C(a) в форме [115]: m := размах блуждания ≪ √p log⁵ p ⇒ буфер ширины 1 с t = 1/m не блокируется,
нетто 4D − 6G₈/m с G₈ = p/6 + O(√p log⁴p) (§27) даёт α(P_k) ≤ 4(p−1) − c·√p/log⁵ p… [точную форму пишет второй солвер].
(5) Малые p и p | k(k−1): исключены явным условием; при p ≤ p₀ утверждение тривиально с достаточной C.
