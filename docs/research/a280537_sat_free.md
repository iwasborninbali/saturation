# A280537 при n = 3, 4, 5: значения доказаны без всякого SAT

Первый солвер, 2026-08-20. Здесь нет ни кодировки, ни решателя, ни сертификата. Компланарность
четырёх точек проверяется определителем разностей; слова «плоскость» в коде нет.

## Верхние границы

Перебор ведётся по орбитам ТРОЕК профилей слоёв (по осям x, y, z). Разбиение исчерпывающе, потому
что у всякой конфигурации есть определённый профиль вдоль каждой оси; орбитальное сокращение
законно, потому что симметрия куба переносит конфигурацию вместе с её профилями.

    n=3, M=9:  орбит  1, сумма весов   1 из   1 троек, конфигураций 0  ->  a(3) <= 8
    n=4, M=11: орбит  4, сумма весов  64 из  64 троек, конфигураций 0  ->  a(4) <= 10
    n=5, M=14: орбит 10, сумма весов 125 из 125 троек, конфигураций 0  ->  a(5) <= 13

Сумма весов сверена с полным числом троек в каждой строке: покрытие полное, пропущенных кусков
нет. Пропуск даже одной орбиты обесценил бы всё.

## Нижние границы

Свидетели предъявлены и проверены по всем четвёркам: 8 точек при n=3, 10 при n=4, 13 при n=5.

## Отсюда — точные значения

    a(3) = 8    a(4) = 10    a(5) = 13

доказаны полностью независимо от SAT: и снизу, и сверху. Это не пересказ известного — это второй
путь к нему, не разделяющий с первым ни строчки кода.

## Дополнительно: сверка по КОЛИЧЕСТВУ, а не по максимуму

    n=3:    16 помеченных конфигураций ->   1 класс   (опубликовано: единственная)
    n=4: 10 960 помеченных             -> 232 класса  (опубликовано: 232)
    n=5:  1 768 помеченных             ->  38 классов (опубликовано: 38)

Внутри каждой строки сходится контрольная сумма `sum(48/|стабилизатор|)` с общим числом. Совпасть
по максимуму две программы с одинаковой ошибкой могут случайно; совпасть трижды по количеству —
практически нет.

## Чего здесь НЕТ

* при n = 6 этот путь не доходит: измеренная стоимость около 70 часов на четырёх ядрах
  (см. `negative/no4_n6_dfs_infeasible.md`), поэтому калибровка на a(6)=16 остаётся одинарной;
* при n = 7 верхней границы нет ни у одного из наших путей; предъявимо только a(7) >= 18.
