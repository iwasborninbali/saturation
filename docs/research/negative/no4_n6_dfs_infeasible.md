# Отрицательный результат: a(6) ≤ 16 для A280537 перебором без SAT — не считается

Первый солвер, 2026-08-20. Записано после измерения, а не после того, как надоело ждать.

## Что задумывалось

Второй солвер закрывает `a(6) ≤ 16` через SAT: кодировка плоскостей, разбиение, отсечение,
решатель, сертификаты. Мой перебор на C не разделяет с этим путём ни строчки: компланарность
считается определителем на четвёрке, слова «плоскость» в коде нет. Совпадение двух таких путей
на значении, доказанном до нас исчерпывающим перебором, было бы лучшей калибровкой, какую мы
можем себе позволить.

## Что было сделано, прежде чем признать невозможность

* инкрементальная блокировка вместо перебора троек на каждого кандидата (ускорение вчетверо);
* блокировка только индексов выше добавляемого — без этого ускорение не окупалось вовсе;
* профиль слоёв по трём осям вместо двух;
* сокращение по орбитам: 216 троек профилей при n=6, M=17 сворачиваются в 10 представителей;
* верхняя оценка остатка по каждой из трёх осей с минимизацией.

Каждый шаг проверялся суммой по всем кускам при n=4: **10 960 после каждого изменения ядра**.

## Измерение вместо ожидания

Десять представителей шли больше получаса без единого завершения. Вместо того чтобы ждать
дальше, оценил размер дерева по Кнуту (`slack/targets/no4_estimate.c`): от корня случайным
потомком, домножая на число потомков в каждом узле.

Оценщик откалиброван на кусках, чьё истинное число узлов известно точно:

    n=4 [3,3,3,1]³:  истина 38 882    оценка 1.1e4   -> занижает в 3.5 раза
    n=4 [2,2,3,3…]:  истина 271 362   оценка 6.9e4   -> занижает в 4.0 раза
    n=4 [1,3,3,3…]:  истина 108 958   оценка 2.7e4   -> занижает в 4.0 раза

Смещение устойчиво: около четырёх. При n=6, M=17 оценка даёт **2·10⁹ узлов на представитель**,
то есть с поправкой около 8·10⁹. Скорость при n=6 — примерно 80 тысяч узлов в секунду (стоимость
узла растёт как |S|²·NC). Отсюда:

    ~28 часов на один представитель, ~70 часов на все десять при четырёх ядрах

И это оценка СНИЗУ: отношение среднего к медиане равно 31, то есть распределение с тяжёлым
хвостом, а при таком хвосте несмещённая по построению оценка на конечном числе спусков
систематически недобирает.

## Вывод

Путь закрыт не потому, что надоело, а потому, что измерен. Стоимость измерения — пятнадцать
минут; стоимость молчаливого продолжения — трое суток на четырёх ядрах и отсутствие результата.

Отдельно: отрицательный результат узкий. Он НЕ означает, что перебор без SAT бесполезен для
A280537 — при n ≤ 5 он даёт точные значения за секунды и воспроизводит опубликованные количества
конфигураций. Он означает ровно одно: **при n=6 и M=17 этот перебор не доходит**, и калибровку
на значении, доказанном до нас, придётся получать от SAT-пути, а не от двух независимых.
