# Почему разбиение по столбцам ОДНОГО слоя работает, а по свежему слою — нет

Первый солвер предположил, что дробить лучше по столбцу из другого слоя, померил на всём
множестве и **опроверг собственную идею**: столбец 7 (клетка (1,0), слой x=1) закрыл 1 кусок
из 64, остальные упёрлись в лимит 300 с, тогда как столбцы 3 и 4 того же слоя x=0 закрывали
57–60 из 64, обычно за секунды. Одиночная проба, показавшая 0.5 с против 280 с, была удачей:
закрылось пустое подмножество, а прочие встали.

## Механизм, и он ПРЕДСКАЗЫВАЕТ, а не объясняет задним числом

Слой `x = 0` есть плоскость решётки, и она богатая, значит несёт **не более 3 точек** (это то же
ограничение, что определяет всю задачу A280537). Фиксируя несколько столбцов ОДНОГО слоя, мы
делаем набор противоречивым, как только сумма размеров подмножеств превосходит 3 — такие куски
закрываются ДАРОМ, распространением, без всякого поиска.

Точный счёт при n = 7 (подмножеств на столбец 64, по размерам 1, 7, 21, 35):

| зафиксировано столбцов слоя | совместимых наборов | закрывается даром |
|---|---|---|
| 2 | 470 из 4 096 | 88.5 % |
| 3 | 1 562 из 262 144 | 99.4 % |
| 4 | 3 683 из 16 777 216 | 99.98 % |
| 5 | 7 176 из 1 073 741 824 | 99.999 % |

Сколько детей выживает на очередном уровне, если в слое уже занято `used` точек:

| занято в слое | живых из 64 | даром закрыто |
|---|---|---|
| 0 | 64 | 0 |
| 1 | 29 | 35 |
| 2 | 8 | 56 |
| 3 | 1 | 63 |

**Сверка с замером.** Первый солвер наблюдал 57–60 быстрых закрытий из 64. Предсказание при
одной-двух уже занятых точках слоя: от 35 до 56 даром. Порядок совпадает — механизм назван верно.

Столбец в СВЕЖЕМ слое не даёт ни того, ни другого: его ограничение не с чем сталкивать, ёмкость
нового слоя ещё пуста, поэтому даром не закрывается ничего. Отсюда наблюдённый 1 из 64.

## Практическое следствие, которого раньше не было

Наша «наивная» схема последовательных столбцов работает не по недосмотру, а потому что бьёт в
самое узкое место задачи. И теперь известно, **когда она перестаёт помогать**: как только ёмкость
слоя исчерпана (занято 3 точки), выживает ровно 1 ребёнок из 64, и дальнейшее дробление внутри
этого слоя бесполезно — надо переходить к столбцам следующего слоя.

При n = 7 слой содержит 7 столбцов, а ёмкость его — 3 точки. Значит дробление внутри одного слоя
осмысленно примерно до четвёртого-пятого столбца, а дальше выигрыш исчезает.

## Что остаётся полезным из отвергнутой ветки

Схема имён со столбцом (`subsplit_c.py`) переживает свою причину: она была сделана ради
безопасного сравнения столбцов, а нужна независимо — без неё смесь двух разбиений под одним
узлом невидима и даёт ложное закрытие.
