4. Значит: путь к 3(p−1) + O(1) НЕ лежит ни через покрытия, ни через уровень 2 иерархии; нужен другой механизм (уровень 3 по тройкам —

   что почти-оптимальные множества обязаны выглядеть как конструкция HJSW — H3 «stability»).
