# Константа порога: независимая проверка

Первый солвер. Построено по собственному выводу, без чтения кода второго солвера — та же проверка
независимости, что была сделана на деревьях, но на ЧИСЛЕ.

## Вывод

Коллинеарная тройка однозначно определяется своей средней точкой, поэтому число троек равно сумме
по неупорядоченным парам числа целых точек строго между ними, а между (0,0) и (a,b) их ровно
gcd(a,b)−1:

    T(n) = 2·Σ_{a,b≥1}(n−a)(n−b)(gcd(a,b)−1) + 2n·Σ_{a≥1}(n−a)(a−1)

Прямая сумма стоит O(n²). Свёртка Дирихле убирает её до O(n log n):
gcd(a,b) = Σ_{d | gcd} φ(d), откуда Σ (n−a)(n−b)gcd = Σ_d φ(d)·(Σ_{d|a}(n−a))².

Порог — наименьшее m, при котором ожидание числа правильных m-множеств падает ниже единицы:
`ln C(n², m) = T(n)·C(m,3)/C(n²,3)`.

Двухчленные оценки у нас обоих ложатся по разные стороны от π/√3 (у него 1.81259 и 1.81536,
у меня 1.81175 и 1.81421) — то есть значение внутри вилки у обоих.

## Вторая величина, проверенная отдельно

Асимптотика самих троек. Прирост T(n)/n⁴ на удвоение n должен быть постоянен:

    n:       4000      8000     16000     32000     64000
    прирост  0.210690  0.210692  0.210693  0.210692  0.210691

    (3/π²)·ln2 = 0.210691

Совпадение до шестого знака, пять удвоений подряд. Значит T(n)/n⁴ = (3/π²)·ln n + const.

## Аналитически, для полноты

При m = αn: `ln C(n²,m) ≈ αn(ln n + 1 − ln α)`, а `λ ≈ (3/π²)α³·n·ln n`. Приравнивая старшие члены
при n·ln n: **α = (3/π²)α³, то есть α² = π²/3 и α = π/√3.** Число Гая–Келли (2π²/3)^(1/3)
получается из α³ = 2π²/3 — куб на месте квадрата.
