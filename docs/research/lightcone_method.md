# Световые координаты как рабочий язык задачи (метод, а не метафора)
*(первый солвер, 2026-08-19; по предложению хозяина о «точках в суперпозиции» и «квантах, живущих на скорости света».
Результаты, полученные этим языком: `lightcone_shells.md` (эксперимент с четвёркой), `slack/null_search.py` (алгоритм),
и — задним числом — весь блочный анализ §30 и раздел «блоки» заметки.)*

## 1. Словарь
Для точки (x, y) коробки положим
   **u = x − y,  v = x + y**   (световые координаты; обратно x = (u+v)/2, y = (v−u)/2).
Тогда для гиперболы H(c) = {xy ≡ c}:
   **xy = c  ⟺  v² − u² = 4c.**
Отсюда сразу:
| объект задачи | в световых координатах |
|---|---|
| гипербола H(c) | массовая оболочка «интервала» 4c (гипербола Минковского) |
| прямая наклона +1 (x − y = const) | u = const — световой луч |
| прямая наклона −1 (x + y = const) | v = const — световой луч |
| строка/столбец | прямые u + v = const / v − u = const, то есть лучи ВТОРОЙ (повёрнутой на 45°) световой пары |
| преобразование (x, y) ↦ (λx, λ⁻¹y) | буст (лоренцево вращение), сохраняющий каждую оболочку; группа порядка p−1 |
| отражение (x, y) ↦ (y, x) | обращение времени (u ↦ −u) |
| «квант на скорости света» | точка, свободно скользящая вдоль u = const или v = const |

## 2. Что этот язык ОБЪЯСНЯЕТ (уже полученное, но теперь без магии)
1. **Почему ±1 прямые особые.** Они — световые лучи формы v² − u², а именно эта форма задаёт наши кривые. Любая другая прямая пересекает
   оболочку не более чем в 2 точках (в вычетах), поэтому «богатые» прямые могут быть только световыми или строками/столбцами.
2. **Почему граф соседей ходит шагами ±1** (§30, блоки): точка на H(c) имеет v² − u² = 4c; переход между оболочками, отличающимися на 4,
   и есть «соседство»; в переменной t = u²/4 это шаг ±1. То есть блочное разложение = разбиение по СОСЕДНИМ МАССОВЫМ ОБОЛОЧКАМ.
3. **Почему k = ±1 особый** (моё [176]): у пары H(1) ∪ H(k) граф соседей имеет шаги 1 и k; при k = ±1 они совпадают (одна «лестница
   оболочек») ⇒ средняя степень 1 ⇒ компоненты O(log p); при любом другом k степень 2 — критическая перколяция, компоненты ~p^{2/3}.
4. **Почему устойчивость (H3) орбитная.** V‑орбита {κ, σκ, τκ, νκ} — это орбита группы, порождённой отражениями u ↦ −u, v ↦ −v; в световых
   координатах это просто ±u, ±v, и «богатая прямая не покидает орбиту» становится очевидным утверждением о лучах.
5. **Ось «суперпозиции».** Ослабление «каждому x — свой y» до «каждому x — несколько допустимых y» = объединение нескольких оболочек;
   вопрос «сколько даёт объединение» становится вопросом о лестнице оболочек, а не о случайном наборе кривых.

## 3. Что этот язык ДАЁТ как метод
* **Алгоритм.** Элементарный ход поиска — скольжение точки вдоль светового луча (u = const или v = const) с возможным переходом на другую
  оболочку ((x+t)(y+t) = c + t(x+y+t)). Отжиг с такими ходами (`slack/null_search.py`) находит ТОЧНЫЕ оптимумы пары при p = 13, 17, 19
  за секунды, тогда как «наивный» диффузионный сэмплер по амплитудам (`slack/diffusion_sampler.py`) недобирает 5–10 %.
* **Постановка вопросов.** «Сколько добавляет m‑я оболочка» — правильная мера не отношение к N, а прибавка над 3(p−1) (у нас она оказалась
  плоской: +7…+8, то есть O(1); см. §5 `lightcone_shells.md`).
* **Проверка гипотез о «локальности».** Информационный горизонт правила естественно измеряется в световых лучах: правило радиуса r видит
  только точки, соединённые ≤ r лучами. Наши отрицательные результаты (орбитно‑локально выигрыш 0, парно ≤ 0.2(p−1)) — это утверждения
  именно о таком горизонте.

## 4. Границы аналогии (честно)
Аналогия точна на уровне КВАДРАТИЧНОЙ ФОРМЫ и её группы; она не даёт ни динамики, ни причинности: «время» здесь — не параметр эволюции,
а координата, а «буст» не сохраняет коробку (он перемешивает представителей, поэтому не является симметрией задачи в окне — только
симметрией вычетной картины). Именно поэтому все выводы получены счётом, а не переносом физических теорем.
