# Чем сужать поиск: обогащение недостаточно, нужна необязательность

Первый солвер, 21 августа 2026. Полный материал, n=4, все 10 960 максимумов.

## Откуда вопрос

Локальное улучшение в этой задаче не работает и работать не может: максимумы **рассеяны** — два
разных максимума делят 1.79 точки из 10 при случайных 1.56 (в плоскости 4.81 из 14 против 4.00).
Понятия «ближайший максимум» не существует. Значит выигрыш поиска — не качество спуска, а
**отбор области**, и улучшать надо отбор.

За две смены: семь попыток улучшить спуск (фильтры, окрестности, правила выбора, ускорения) дали
ноль или отрицательное; единственный прирост дала смена пространства с клеток на орбиты.

## Измерение

Обогащение = доля максимумов со свойством, делённая на долю случайных наборов того же размера.

    свойство                              у максимумов   у случайных   обогащение
    все направления различны                 100.00 %      0.0015 %     ×66667
    слоёв ровно с тремя точками >= 2         100.00 %     29.89   %     ×3.35
    различных сумм координат <= M/2           10.22 %     33.82   %     ×0.30
    различных сумм координат >= M-1            0.00 %      0.28   %     ×0
    ни в одном слое нет трёх точек             0.00 %      0.00   %     —

## Критерий, без которого таблица читается неверно

**Обогащение годно для сужения только если область НЕ СЛЕДУЕТ из самого запрета.**

    направления различны — следует: два параллельных отрезка компланарны, значит у всякой
        правильной конфигурации все C(M,2) направлений различны. ×66667 есть переформулировка
        запрета, и сужать ею нечего: всякий правильный перебор уже сидит внутри.

    два полных слоя — следует: при n=4, M=10 один полный слой даёт максимум 3+2+2+2 = 9 < 10.
        ×3.35 — то же самое.

    симметрия — НЕ следует, и доказано её собственным провалом: при n=6 циклически-инвариантное
        подпространство не содержит ни одного максимума. Обогащение >= ×12843 при n=5.

**Единственная настоящая ось сужения у нас одна.** Больше ни одного необязательного и при этом
обогащённого ограничения найти не удалось — это отрицательный результат на полном материале,
а не отсутствие попытки.

## Дименсионное различие, попутно

Второй солвер предположил, что обогащена область с МАЛЫМ числом различных направлений (в плоскости
этот признак у него что-то различал). В кубе она **пуста**: у максимумов направлений не мало,
а предельно много. Причина в размерности: в плоскости запрет трёх на прямой допускает параллельные
пары — две точки на одной прямой и две на параллельной трёх на прямой не дают, — поэтому число
направлений там гуляет. В кубе четыре точки двух параллельных отрезков компланарны, и оно константа.

Инструмент: `slack/targets/regions.py`, считает за минуту на любом полном материале.

## Второе условие годности (второй солвер), и почему нужны оба

Моё условие ловит область, которая **следует из запрета**. Второй солвер нашёл второе, ловящее
другое: область не должна **содержаться в оси, которая уже есть**.

В плоскости «мало различных направлений» из запрета не следует (параллельные пары там разрешены),
и обогащение реально: ×9.2, ×3.5, ×5.3, ×2.8 при n=7…10. Но если убрать симметричные максимумы
из числителя И из базы:

    n=8  (320 несимметричных из 380)   ×3.6  ->  ×0.0
    n=9  (328 из 368)                  ×5.3  ->  ×0.0
    n=10 (1056 из 1135)                ×2.9  ->  ×0.0

**Ни один несимметричный максимум не попадает в эту область.** Всё обогащение — тень симметрии,
та же ось через более слабую линзу.

**Критерий целиком: область годна, если она (1) не следует из запрета и (2) не содержится в уже
имеющейся оси.** Каждое условие пропускает то, что ловит другое: мои ×66667 прошли бы второе
условие (они не в симметрии), его ×9.2 прошли бы первое (в плоскости они не следуют из запрета).

Симметрия удовлетворяет обоим. Больше ни одна проверенная область — ни в кубе, ни в плоскости.

## Побочно: почему утренняя граница по направлениям не могла быть сильной

Из различности направлений выводилась граница C(m,2) ≤ D(n), и она оказалась слабее тривиальной
при всех n; тогда это объяснялось ростом отношения запас/спрос как 0.74n. Настоящая причина проще
и общее: **эта граница есть переформулировка запрета, а не дополнение к нему.** Переформулировка
не может быть сильнее того, что переформулирует.
