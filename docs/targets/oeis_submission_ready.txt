%I A000000
%S A000000 1,8,16,28,40,64
%N A000000 a(n) = maximal number of points in the n X n X n grid with no three of them collinear.
%C A000000 Collinearity is meant in the ordinary sense: three points of {0,1,...,n-1}^3 are excluded when they lie on a common line in R^3, tested by an integer cross product. Not "coplanar" and not "collinear modulo n".
%C A000000 a(n) <= 2*n^2, since each of the n^2 lines parallel to an axis contains at most 2 chosen points; a(2) = 8 attains this bound.
%C A000000 a(n) = Theta(n^2) by A. Por and D. R. Wood.
%C A000000 Lower bounds for further terms, all witnesses checked by exhaustive integer arithmetic over every triple: a(7) >= 72, a(8) >= 90.
%C A000000 a(p) >= p^2 for every prime p: let Q be an anisotropic binary quadratic form over GF(p) (that is, Q(a,b) = 0 only for a = b = 0; for instance x^2 - d*y^2 with d a non-residue, which exists for every p). Then {(x, y, Q(x,y) mod p) : 0 <= x,y < p} has p^2 points and no three collinear. Proof: three collinear points in R^3 project onto a line with primitive integer direction (a,b), with integer parameters t_i, |t_i| < p, pairwise distinct mod p; along that line z = Q(x0 + t*a, y0 + t*b) is a quadratic polynomial in t with leading coefficient Q(a,b), and collinearity forces it to be affine, so Q(a,b) = 0 (mod p), whence (a,b) = (0,0), a contradiction. Verified for p = 3, 5, 7, 11, 13. The special case Q = x^2 + y^2 works only for p = 3 (mod 4).
%C A000000 Structure of the optima. Writing the layer profile as the number of points in each of the n layers perpendicular to an axis, every optimum found has the same profile along all three axes: n=2: 4,4; n=3: 6,4,6; n=4: 8,6,6,8; n=5: 8,8,8,8,8; n=6: 12,10,10,10,10,12. A layer is an n X n grid with no three collinear, hence carries at most 2n points. For n = 2, 3, 4, 6 the two outer layers attain that planar maximum and the inner ones carry 2n-2, giving 2*n^2 - 2*n + 4, which reproduces 8, 16, 28 and 64.
%C A000000 An anomaly at n = 5: the profile 10,6,8,6,10 is infeasible even though its total is only 40, when prescribed along any single axis. Hence at n = 5 two outer layers cannot both attain the planar maximum 2n at any total, and the optimum is forced onto the uniform profile. At n = 7 the profile 14,12,12,12,12,12,14 (total 88) is likewise infeasible, while at n = 6 the analogous profile is realisable. The mechanism is not known.
%e A000000 a(2) = 8: all eight points of the 2 X 2 X 2 cube may be taken, since no line contains three points of that grid.
%H A000000 A. Por, D. R. Wood, <a href="https://doi.org/10.1007/s00453-006-0158-9">No-Three-in-Line-in-3D</a>, Algorithmica 47 (2007), 481-488.
