## %N (название)
`a(n) = maximal number of points in the n X n X n grid with no three of them collinear.`

Формулировка намеренно точная: решётка `{0,1,...,n-1}^3`, коллинеарность — в **обычном смысле** (три точки на одной прямой
в R³, проверяется целочисленным векторным произведением), а не «в одной плоскости» и не по модулю n.

## %S (данные) — только ДОКАЗАННЫЕ члены
```
1, 8, 16, 28
```
(a(1)=1, a(2)=8, a(3)=16, a(4)=28.)
**После завершения перебора добавить a(5)=40**, если он подтвердится, — и только тогда.

## %C (комментарии)
1. `a(n) = Theta(n^2)` — A. Pór, D. R. Wood, "No-Three-in-Line-in-3D", Algorithmica 47 (2007), 481-488.
2. Тривиальная верхняя граница `a(n) <= 2n^2`: каждая из `n^2` прямых, параллельных оси, содержит не более 2 выбранных точек.
3. Известные **нижние** границы, полученные исчерпанной проверкой конфигураций (все проверены перебором всех троек в целочисленной
   арифметике): `a(5) >= 40, a(6) >= 64, a(7) >= 72, a(8) >= 90`. (обновить после n = 9, 10)
4. **Нижняя граница a(p) >= p^2 для КАЖДОГО простого p.**  Пусть Q — анизотропная бинарная квадратичная форма над F_p
   (то есть Q(a,b) = 0 только при a = b = 0; например x^2 - d y^2 с невычетом d — такая существует для любого p).
   Тогда множество {(x, y, Q(x,y) mod p) : 0 <= x,y < p} состоит из p^2 точек, среди которых нет трёх коллинеарных.
   Доказательство: если три точки коллинеарны в R^3, их проекции лежат на прямой с примитивным целым направлением (a,b),
   параметры t_i целые, |t_i| < p, попарно различны по модулю p; вдоль прямой z = Q(x0 + t a, y0 + t b) — квадратичный
   многочлен от t со старшим коэффициентом Q(a,b), а коллинеарность требует аффинности, откуда Q(a,b) = 0 (mod p) и,
   по анизотропности, (a,b) = (0,0) — противоречие.  Проверено перебором всех троек при p = 3, 5, 7, 11, 13.
   ЗАМЕЧАНИЕ: частный случай Q = x^2 + y^2 работает ТОЛЬКО при p = 3 (mod 4); при p = 1 (mod 4) есть явные тройки
   (p = 5: (0,0,0), (1,2,0), (2,4,0)).  Граница p^2 слабее найденной вычислением (49 против 72 при p = 7).
5. Двумерный аналог — задача no-three-in-line, где максимум равен `2n` для `n <= 46` (A000769 и таблица А. Фламменкампа).

## %e (пример)
`a(2) = 8`: все восемь точек куба 2 X 2 X 2 годятся, поскольку никакая прямая не содержит трёх точек этой решётки.
