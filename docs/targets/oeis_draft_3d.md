## %N (название)
`a(n) = maximal number of points in the n X n X n grid with no three of them collinear.`

Формулировка намеренно точная: решётка `{0,1,...,n-1}^3`, коллинеарность — в **обычном смысле** (три точки на одной прямой
в R³, проверяется целочисленным векторным произведением), а не «в одной плоскости» и не по модулю n.

## %S (данные) — только ДОКАЗАННЫЕ члены
```
1, 8, 16, 28
```
(a(1)=1, a(2)=8, a(3)=16, a(4)=28.)
**После завершения перебора добавить a(5)=40**, если он подтвердится, — и только тогда.

## %C (комментарии)
1. `a(n) = Theta(n^2)` — A. Pór, D. R. Wood, "No-Three-in-Line-in-3D", Algorithmica 47 (2007), 481-488.
2. Тривиальная верхняя граница `a(n) <= 2n^2`: каждая из `n^2` прямых, параллельных оси, содержит не более 2 выбранных точек.
3. Известные **нижние** границы, полученные исчерпанной проверкой конфигураций (все проверены перебором всех троек в целочисленной
   арифметике): `a(5) >= 40, a(6) >= 64, a(7) >= 72, a(8) >= 90`. (обновить после n = 9, 10)
4. Для простого `p ≡ 3 (mod 4)` множество `{(x, y, (x^2+y^2) mod p) : 0 <= x,y < p}` состоит из `p^2` точек, никакие три из
   которых не коллинеарны, что даёт `a(p) >= p^2`. ДОКАЗАТЕЛЬСТВО (5 строк): если три точки коллинеарны в R³, их проекции
   на плоскость (x,y) лежат на прямой с примитивным целым направлением (a,b), параметры t_i целые и попарно различны по
   модулю p (все |t_i| < p); вдоль прямой `z ≡ (x0²+y0²) + 2t(x0 a + y0 b) + t²(a²+b²) (mod p)`, а коллинеарность в R³ требует,
   чтобы z была АФФИННОЙ функцией t; квадратичный многочлен по модулю p, совпадающий с линейным в трёх различных точках,
   обязан иметь нулевой старший коэффициент, то есть `a² + b² ≡ 0 (mod p)`; при `p ≡ 3 (mod 4)` число −1 не является квадратом,
   поэтому отсюда a ≡ b ≡ 0 (mod p), что при |a|,|b| < p даёт (a,b) = (0,0) — противоречие. ∎
   ВАЖНО: при `p ≡ 1 (mod 4)` конструкция НЕВЕРНА — уравнение a²+b² ≡ 0 имеет нетривиальные решения, и коллинеарные тройки
   появляются: при p = 5 это, например, (0,0,0), (1,2,0), (2,4,0); при p = 13 — (0,0,0), (1,5,0), (2,10,0) (проверено перебором
   всех троек: p = 3, 7, 11 — троек нет; p = 5, 13 — есть).
   Полученная граница слабее найденных вычислением: при p = 7 конструкция даёт 49 против 72.
5. Двумерный аналог — задача no-three-in-line, где максимум равен `2n` для `n <= 46` (A000769 и таблица А. Фламменкампа).

## %e (пример)
`a(2) = 8`: все восемь точек куба 2 X 2 X 2 годятся, поскольку никакая прямая не содержит трёх точек этой решётки.
