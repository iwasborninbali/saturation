## %N (название)
`a(n) = maximal number of points in the n X n X n grid with no three of them collinear.`

Формулировка намеренно точная: решётка `{0,1,...,n-1}^3`, коллинеарность — в **обычном смысле** (три точки на одной прямой
в R³, проверяется целочисленным векторным произведением), а не «в одной плоскости» и не по модулю n.

## %C (комментарии)
1. `a(n) = Theta(n^2)` — A. Pór, D. R. Wood, "No-Three-in-Line-in-3D", Algorithmica 47 (2007), 481-488.
2. Тривиальная верхняя граница `a(n) <= 2n^2`: каждая из `n^2` прямых, параллельных оси, содержит не более 2 выбранных точек.
3. Известные **нижние** границы для последующих членов (все свидетели проверены перебором всех троек
   в целочисленной арифметике): `a(7) >= 72, a(8) >= 90`.
6. **Структура оптимумов и аномалия при n=5.** Профиль слоёв (число точек в каждом из n слоёв,
   перпендикулярных оси) у всех найденных оптимумов ОДИНАКОВ по всем трём осям:
   n=2: 4,4; n=3: 6,4,6; n=4: 8,6,6,8; n=5: 8,8,8,8,8; n=6: 12,10,10,10,10,12.
   Слой есть плоская решётка n x n без трёх коллинеарных, поэтому несёт не более 2n точек.
   При n=2,3,4,6 крайние слои достигают этого потолка, а внутренние несут 2n-2, что даёт
   2n^2-2n+4 — в точности 8, 16, 28 и 64. При n=5 это НЕВОЗМОЖНО, и в сильной форме:
   профиль 10,6,8,6,10 (сумма всего 40) невыполним при задании по любой ОДНОЙ оси, то есть два
   крайних слоя не могут одновременно нести планарный максимум ни при какой сумме; оптимум
   вынужденно равномерен. При n=7 профиль 14,12,12,12,12,12,14 (сумма 88) также невыполним.
   Механизм неизвестен; косвенно на него указывает бедность планарных максимумов при n=5
   (32 конфигурации в 5 классах против 50 в 11 классах при n=6).
4. **Нижняя граница a(p) >= p^2 для КАЖДОГО простого p.**  Пусть Q — анизотропная бинарная квадратичная форма над F_p
   (то есть Q(a,b) = 0 только при a = b = 0; например x^2 - d y^2 с невычетом d — такая существует для любого p).
   Тогда множество {(x, y, Q(x,y) mod p) : 0 <= x,y < p} состоит из p^2 точек, среди которых нет трёх коллинеарных.
   Доказательство: если три точки коллинеарны в R^3, их проекции лежат на прямой с примитивным целым направлением (a,b),
   параметры t_i целые, |t_i| < p, попарно различны по модулю p; вдоль прямой z = Q(x0 + t a, y0 + t b) — квадратичный
   многочлен от t со старшим коэффициентом Q(a,b), а коллинеарность требует аффинности, откуда Q(a,b) = 0 (mod p) и,
   по анизотропности, (a,b) = (0,0) — противоречие.  Проверено перебором всех троек при p = 3, 5, 7, 11, 13.
   ЗАМЕЧАНИЕ: частный случай Q = x^2 + y^2 работает ТОЛЬКО при p = 3 (mod 4); при p = 1 (mod 4) есть явные тройки
   (p = 5: (0,0,0), (1,2,0), (2,4,0)).  Граница p^2 слабее найденной вычислением (49 против 72 при p = 7).
5. Двумерный аналог — задача no-three-in-line, где максимум равен `2n` для `n <= 46` (A000769 и таблица А. Фламменкампа).

## %e (пример)
`a(2) = 8`: все восемь точек куба 2 X 2 X 2 годятся, поскольку никакая прямая не содержит трёх точек этой решётки.

## Метод (переписан 2026-08-20: перебор заменён на SAT с сертификатом)

Прямая, содержащая не более двух узлов решётки, ничего запретить не может, поэтому

> S ⊆ [n]³ допустимо ⟺ для КАЖДОЙ прямой L с ≥ 3 узлами решётки: |S ∩ L| ≤ 2.

Это булева задача на n³ переменных (125 при n = 5, 216 при n = 6). Кодировка: at-most-2 на каждую
богатую прямую, глобальный тотализатор с обрезкой на 2n² (обрезка законна: каждая из n² прямых,
параллельных оси, несёт ≤ 2 точки), 47 лексикографических ограничений по группе куба.

**Почему не перебор.** Наш префиксный перебор n = 5 на 42 ядрах за два часа закрыл 5 префиксов из 204
(экстраполяция ≈ 88 ядро-суток), тогда как SAT закрывает те же вопросы за минуты. Но решающее не
скорость: UNSAT даёт **сертификат DRAT**, проверяемый эталонной чужой программой `drat-trim`, тогда как
полнота перебора доказывается нашим собственным аргументом о покрытии префиксов.

**Цепь доверия — три разных звена** (подробнее в `docs/HANDOVER.md`, раздел 3б):
1. CNF выражает задачу — проверено двумя независимыми способами (сравнение множеств запрещённых троек
   со списком прямых; сквозной прогон через решатель с форсированием каждой коллинеарной тройки).
   При n = 4 и n = 5: 376 и 1858 коллинеарных троек, ноль незапрещённых, ноль лишних.
2. CNF невыполним — проверяет `drat-trim`, не доверяя ни kissat, ни нам.
3. Свидетель допустим — перебор ВСЕХ троек целочисленными векторными произведениями.

Калибровка кодировки по известным значениям: a(3)=16 и a(4)=28 — UNSAT при +1 за доли секунды,
на двух разных машинах независимо.
