Two independent programs for A398172 (number of subsets of the n X n grid with no three
collinear points, the empty set counted) and A398184 (number of maximal such subsets).
Both are exhaustive depth-first enumerations; they share no code and were written
separately. Each reproduces a(1)..a(7) of both sequences:
  A398172: 2, 16, 230, 4812, 109536, 3599697, 101612896
  A398184: 1, 1, 23, 347, 5646, 116411, 2445518
Subsets are counted as sets of grid points; rotations and reflections are not identified.

Program 1 (Python 3): recursion over the cells in a fixed order; a cell may be added
only if it does not complete a collinear triple with two cells already chosen.

from itertools import combinations
def a(n):
    cells = [(r, c) for r in range(n) for c in range(n)]; N = len(cells); ix = {c: i for i, c in enumerate(cells)}
    coll = [[] for _ in range(N)]
    for p, q, r in combinations(cells, 3):
        if (q[0]-p[0])*(r[1]-p[1]) - (q[1]-p[1])*(r[0]-p[0]) == 0:
            i, j, k = ix[p], ix[q], ix[r]; coll[i].append((j, k)); coll[j].append((i, k)); coll[k].append((i, j))
    inS = [False]*N
    def rec(k):
        if k == N: return 1
        t = rec(k + 1)
        if not any(inS[i] and inS[j] for i, j in coll[k]):
            inS[k] = True; t += rec(k + 1); inS[k] = False
        return t
    return rec(0)

For A398184 the same recursion counts, at k == N, only the complete subsets S for which

Program 2 (Python 3): bitmask search. L[i][j] is the set of cells on the line through
cells i and j; F is the set of cells blocked by the chosen pairs. Returns (A398172(n), A398184(n)).

from math import gcd
def A398172_A398184(n):
    N = n*n; P = [(i//n, i%n) for i in range(N)]; L = [[0]*N for _ in range(N)]
    for i in range(N):
        for j in range(i+1, N):
            dx, dy = P[j][0]-P[i][0], P[j][1]-P[i][1]; g = gcd(dx, dy); dx //= g; dy //= g
            L[i][j] = L[j][i] = sum(1 << k for k in range(N) if k != i and k != j and (P[k][0]-P[i][0])*dy == (P[k][1]-P[i][1])*dx)
    full = (1 << N) - 1; cnt = [0, 0]
    def dfs(start, S, chosen, F):        # F = cells lying on a line through two chosen points (forbidden)
        cnt[0] += 1
        if S | F == full: cnt[1] += 1    # maximal: every free cell is forbidden
        for c in range(start, N):
            if not F >> c & 1:
                G = F
                for s in chosen: G |= L[s][c]
                dfs(c+1, S | 1 << c, chosen + [c], G)
    dfs(0, 0, [], 0); return cnt[0], cnt[1]
