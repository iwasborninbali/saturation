## 1. no3_3d_note — СРОЧНО: фантомные числа всё ещё в тексте (и в Zenodo лежит утренняя версия)

В абзаце «Removing link 1» до сих пор стоит: «brute-forced all $2\,220\,075$ subsets at $n=3$,
obtaining $16$ … the count $10\,960$ at $n=4$». Оба числа не описывают эту задачу (внешний аудит,
23.08): истинное число лояльных подмножеств 3^3 равно 3 813 884 (с пустым), максимум 16 достигают
ровно 2 подмножества; 28-точечных максимумов при n=4 ровно 14 (три D4-класса, стабилизаторы 8, 8,
24; у всех профиль (8,6,6,8) по всем осям). 2 220 075 = C(27,8) — это перебор восьмиточечных
подмножеств из перечислений no-4-coplanar; происхождение 10 960 — проверить по своим журналам
(grep 10960 по logs/), гипотеза: помеченные максимумы no-4-coplanar при n=4 (232 класса).

ПОЧЕМУ ПРОПУСТИЛИ: в tex числа записаны как «2\,220\,075» (с бэкслэш-запятыми LaTeX) — грепы по
«2,220,075» и «2220075» их НЕ находят. Урок в гейт: числовые грепы гонять и по формату с \, .

Дальше: пересобрать PDF (локальный no3_3d_note.pdf сейчас собран из СТАРОГО tex — md5 совпадает с
