## Задача (математическая, отдельная от вычислительных линий первых двух)
Контекст: точки на модульной гиперболе H(c,p) = {xy ≡ c (mod p)} в окне G(p) = [−(p−1)/2, (3p−1)/2]×[0, 2p−1] (KNS,
arXiv 2508.07632, §2.2): каждый класс вычетов имеет 4 копии в вершинах квадрата со стороной p; HJSW берут 3 из 4 и получают
3(p−1) точек без трёх на прямой. Мы вычислили точно (SAT + независимая проверка): максимальное законное подмножество
H(1,p)∩G(p) равно ровно 3(p−1) при p = 7, 11, 13, 17, 19, 23. В литературе это фольклор, не теорема (ресерч №3, вопрос 4).
1. **Докажи (или опровергни) теорему:** для простого p ≥ 7 любое подмножество H(c,p)∩G(p) без трёх коллинеарных точек имеет
   не более 3(p−1) точек. Подсказки: (i) прямая наклона ∉{0,∞,±1} содержит ≤1 точки каждого класса и ≤2 классов (KNS Obs 2.4,
   2.6) ⇒ ограничений не даёт; горизонтали/вертикали содержат ровно один класс ⇒ тоже; всё решают прямые наклона ±1: через
   диагональ квадрата класса (x,y) наклона +1 проходит партнёрский класс (−y,−x), наклона −1 — класс (y,x) (инволюции на
   классах; неподвижные точки при x²≡∓c). Нужно аккуратно учесть, какие копии партнёра попадают в окно (блоки A/B/C/D KNS) —
   тут и живёт доказательство. Проверяй каждый шаг на p=7 руками/скриптом (наш `slack/liftmax.py W p 2p 1 s` даёт точный максимум).
2. **Кросс‑тройки двух гипербол:** для объединения H(1,p) ∪ H(1,q) (p≠q, окно N×N ≈ 2·max(p,q), сдвиг −(p−1)/2 по x для каждого
   модуля) число коллинеарных над Z троек с точками на обеих гиперболах растёт как ≈0.5·N² (наши счёты `slack/crosstriples.py`,
   N=22…82). Дай объяснение/оценку (элементарно или через суммы характеров) и следствие для максимального законного подмножества
   объединения: остаётся ли выигрыш над HJSW O(1) (наши точные максимумы: 32 vs 30 при N=22, 38 vs 36 при N=26).
3. **Независимая проверка:** любые наши числа, которые тебе понадобятся, перепроверь своим кодом (свидетели — через `the_law`).
