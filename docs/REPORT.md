# Отчёт: насыщение (no-three-in-line) — с нашего конца

*Живой документ; обновляется по мере результатов. Все числа — из журналов в `bench/`, все книги — через `saturation.certify`.*

## 1. Задача
`saturation.py` (v1) — слепая формулировка: токены n×n, закон «никакая тройка не вырождена», потолок 2n, насыщение = 2n,
«какие n насыщаются — не записано». Узнана: no-three-in-line (Дьюдени, 1917); 2n-книга = 2n маркеров без трёх на прямой.
Партнёру дали v2 с TARGET=71 (плацдармы); киты объединены в этом репозитории.

## 2. Инструменты (все — здесь, `make && make check`)
- `there.c` — точный поиск: битово-параллельный DFS с рестартами, MRV по строкам и столбцам, затенение всех пар,
  орбиты симметрии (iden/rot2/rot4/dia1/ort1/ort2/dia2/full/rct4), маски попарно несовместимых орбит, полное перечисление,
  достройка при фиксированных токенах (`FIX=`), rot2-пары внутри класса четверти оборота (`PAIRS=`), смешанный класс (`sym 11`).
  `there128` — до n=128. Валидация: A000769 (n=2…10: 1,1,4,5,11,22,57,51,156 ✓), таблицы Фламменкампа (dia1 n=11/13/15: 12/20/28;
  dia2 n=11…25: 0,2,2,0,0,0,2,4; rct4 n=9…21 с точностью до множителя 2 — зеркало диагоналей ✓), трассы `bt.c` партнёра ✓.
- `there.py` — драйвер (параллельные сиды, классы, `books.json`), `there_sat.py` (kissat), `lns.py`, `web/decode.py`,
  `web/stab.py` (точный класс + кодировка базы; round-trip на n=76 ✓), `bench/*` — калибровки.

## 3. Карта сертифицированных книг (`books.json`)
n = 2…30, 32, 34, 36, 38, 40 (rot4/dia2/rot2/rct4/full — по классам), 41 (rct4); очередь: 31, 33, 35, 37, 39 (rct4), 42, 44 (rot4).
Каждая запись: токены, класс, сид, узлы, секунды, сертификат.

## 4. Измерения и законы роста
- Полные деревья: rot2 ×10 на +2 (n=18: 4.9·10⁷ узлов, 1330 книг), dia1 ×9 на +2 (n=19: 7.7·10⁷, 32 книги), rot4 ×20 на +4
  (n=28: 1.2·10⁷, 116 книг), dia2 ×4 на +2 (n=29: 3.2·10⁶, 2 книги).
- Стоимость одной книги: rot4 ×8–10 на +4 (n=36: ~10–60 с на 8 сидах; 40: 70 с), rct4 ×~10 на +4 (41: 806 с; 43: 6.7 ядро-ч
  у партнёра; 45: >3.3 ядро-ч без книги), rot2 ×6 на +2 (24: 10 с; 27: 137 с на 8 сидах).
- Сравнение: CP-SAT Преллберга (arXiv 2602.07751) — то же ×10 на +4, константа хуже нашего DFS в разы; n=60 у него ≈ 60 ядро-лет.

## 5. Состояние в мире (11.08.2026) и вердикт
Известны все n ≤ 70 и 72, 74, 76 (Хойле — SAT; Преллберг — CP-SAT/GPU-код Райли); открыты 71, 73, 75, ≥77.
Инструменты рекордсменов непубличны. Экстраполяция нашей кривой к 71: 10⁵–10⁷ ядро-часов ⇒ облако не арендуем, 71/78 — не наша гонка.

## 6. Отрицательные результаты (все воспроизводимы)
- Локальный поиск на ровно 2n (min-conflicts, SA, ILS): умирает при n≈12–28; плацдармы 128–134 при 71 не достраиваются
  (`FIX=` → «none» мгновенно).
- kissat (наша CNF): проигрывает DFS с n≈27.
- Тёплый старт/LNS от книги n к n+2: 44→46 не достраивается даже при 7 сохранённых орбитах из 22 — соседние размеры не коррелированы.
- «rot4 + одна rot2-пара вне диагонали» — пусто (лемма о балансе, доказана независимо обоими); «C4-орбиты + ≥1 V2-четвёрка»
  — пусто при n≤33; BP-децимация без бэктрекинга — умирает при n≥8.

## 7. Положительные находки
- Лемма о балансе (общая формулировка партнёра): дефект относительно H с движением столбец→строка — эйлеров орграф на классах строк.
- Первая известная книга с точной симметрией rot2 при n=33 из семейства «C4-орбиты + 3-цикл rot2-пар» (партнёр; `docs/SUBMISSION.md`).
- Чётное семейство «C4-орбиты + петля на главной диагонали + петля на побочной» непусто: n=24 — 8 книг, 26 — 4, 28 — 4;
  при 36 (клетка «:» пуста) — развёртка идёт.
