# Итоги проекта на 19.08.2026 (простыми словами) — для хозяина

**Задача.** Сколько точек можно поставить на клетчатой доске N×N так, чтобы никакие три не лежали на одной прямой? Лучшая известная асимптотическая
конструкция (HJSW 1975): точки «модульной гиперболы» xy ≡ c (mod p) в окне 2p×2p — (3/2)·N точек; лучше никто не умеет 50 лет; задача 72 в списке Грина.

**Что доказано в заметке `paper/hjsw_window.pdf` (тег hjsw-note-v1.5):**
1. Одна гипербола в окне HJSW даёт РОВНО 3(p−1) точек — точная структура максимумов (число максимальных множеств 9^s), формула для любого окна 2p×2p,
   аналог для «никаких четырёх на прямой».
2. Среди всех коник только сдвинутые гиперболы дотягивают до 3(p−1) в окне 2p×2p.
3. Две гиперболы xy ≡ ±1: не больше (11/3+o(1))(p−1) — первая оценка ниже тривиальной 4(p−1) для объединения двух гипербол (v1.0–1.2).
4. Любая вторая гипербола xy ≡ k: точная теорема через «потенциал/буфер» на циклах строк‑столбцов и следствие α ≤ 4(p−1) − c√p/log⁵p при почти всех k (v1.4).
5. Ни один кубический график y = f(x) не достигает конструкции HJSW: α ≤ (11/8+o(1))·N < (3/2)N в любом окне 2p×2p (v1.5, доказано первым солвером,
   проверено вторым) — в русле замечания Грина «сформулировать точную гипотезу такого рода и посмотреть, доказывает ли она оптимальность HJSW».

**Основная статья `paper/no3inline_defects.pdf`:** 10 новых конфигураций с точной симметрией поворота (n = 33, 36, 37, 39 — четвёртая для 39 найдена
сегодня утром); 9 опубликованы Фламменкампом с указанием авторства, четвёртая отправлена ему сегодня.

**Что численно верно, но не доказано:** для любой пары гипербол максимум ≈ 3(p−1)+O(1) (данные до p = 29); линейная константа для всех k
(сертификат t = 1/m работает везде, доказательство упирается в «локальный закон» с нелепыми константами); сильная форма для кубик (LP ≈ 1.1·N).
